## 二、新发现

### 【P3-4】HTTP 402（账户余额不足）未归类，只显示原始状态码 — `[真实凭据]`

- **现象**：能力测试对真实硅基流动服务返回 `服务请求失败（402）`。
- **复现步骤**：设置 → 高级工具 → 课表识别（视觉模型）→ 硅基流动卡片「能力测试」。
- **实际结果**：页面顶部显示 `服务请求失败（402）`。
- **预期结果**：错误分类应给出可操作提示。仓库已为其他状态码定义了文案
  （401→「认证失败，请检查 key 与服务权限」、404→「接口或模型不可用」、3xx→「服务重定向已拒绝，请核对接口地址」、
  DNS→「无法解析服务地址，请检查网络与域名」、SSL→「HTTPS 安全连接失败，请检查证书与地址」、
  超时→「服务响应超时，请稍后重试」），**但没有 402 的条目**。
- **影响**：402 是**极常见的真实场景**——用户 key 有效但账户未充值。
  应用内帮助文本自己都写着「免费模型（如 Qwen3-VL-8B）无需充值」，
  说明「未充值」是被预期的用户状态，却只回一个裸状态码，用户无法判断该去充值还是换免费模型。
- **等级**：P3（可用性；非数据安全，不阻断发布）
- **建议**：为 402 增加文案，例如「账户余额不足或该模型需要付费，请充值或改用免费模型」。
- **附带价值**：该结果**反证了已存 key 是有效的**（无效 key 会返回 401 走认证失败分支），
  因此这条记录同时是「认证路径正常」的真机证据。
