# rc.32：真实课表识别定向复测

当前候选：8.3.0-rc.32 / versionCode 566。目标设备为同一台 OPPO / ColorOS 17 / Android 17 测试机。rc.31 的真实课表失败摘要为 `bytes=4485 sha256=9ca64a70a96e syntax=false invalid-json stage=format`。

## 安装

1. 只安装 Run 566（或同一提交后续重跑）对应的稳定签名 APK，不能复用 Run 565/rc.31；最终以 APK 内 versionName/versionCode 核对。
2. 执行 `adb install -r <APK>`，确认 `Success`；核对 `versionName=8.3.0-rc.32`、`versionCode=566`。
3. 保留现有 key、Qwen/Qwen3-VL-8B-Instruct 默认服务和校园生活开关；不要清除数据。
4. 记录计划 → 课程的已确认/待确认计数，并先收起输入法。

## 识别

1. 计划 → 课程 → 截图识别，选择同一张真实课表。
2. 等待一次完整请求，不重复点击；记录是否进入审核页。
3. 若进入审核页，检查候选名称、星期、开始/结束节次、坐标警告；未确定的候选逐条人工处理。
4. 若仍失败，只复制完整括号诊断摘要，尤其是 `stage=` 后的文字；不要复制真实课表或模型原文。
5. 若诊断为 `stage=syntax`，保留新摘要；若为 `stage=candidates`，说明 JSON 已提取但候选结构仍不符合约束。

## 验收门槛

- 通过条件：进入审核页，候选可逐条确认/编辑/拒绝，课程计数只在确认后变化。
- 失败条件：仍显示 `stage=format`、`stage=syntax` 或 `stage=candidates`；不写入课程。
- 不需要重跑 P2 通知、外观、重启或整日 soak；本候选只针对结果提取修复。
