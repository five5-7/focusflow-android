# FocusFlow 统一设计语言与文本减负规范

状态：第一轮已通过自动构建；第二轮代码实施中，等待自动构建、主题截图与真机验收。本文是文本取舍与界面基础规则的唯一规范来源；具体完成状态以代码、CI 与真机验收为准。

## 目标与边界

- 降低界面噪声，让用户内容和下一步操作优先于产品解释。
- 统一层级、间距、组件分工和颜色语义，同时允许课表、时间轴等专业界面保留独特结构。
- 不因视觉整理改变课程、任务、提醒、统计口径或本地数据；不删除必要的风险、异常和操作影响说明。
- 完整教程集中在快速入门、使用说明书和页面帮助；常用页面只显示当前决策真正需要的信息。

## 文本取舍

| 类型 | 规则 |
| --- | --- |
| 重复标题 | 相邻区域只保留一个；控件已经明确表达的说明删除 |
| 常驻教学 | 高频操作不长期讲解，移入首次提示或帮助 |
| 默认值与影响 | 在相关设置旁保留摘要，完整内容使用折叠帮助 |
| 当前状态 | 必须准确区分未开启、未配置、暂无数据和异常 |
| 风险与异常 | 直接显示，并说明用户可采取的下一步 |
| 用户内容 | 标题、课程、任务、地点和备注优先获得空间 |
| 更新信息 | 弹窗只给真实版本号与核心变化，详情进入版本路线图 |

默认文案不得冒充实时状态；动态值不得写死为默认值。按钮、帮助路径、设置名称和实际行为必须一致。

## 基础视觉规则

- 字体层级：页面标题使用 `displaySmall`；区域标题使用 `titleLarge/titleMedium`；正文使用 `bodyMedium/bodySmall`；辅助信息使用 `labelMedium/labelSmall`。
- 间距只从 4、8、12、16、24dp 中选用；普通页面水平边距以 16dp 为基准。
- 页面只保留一个主标题。入口卡用于导航，内容卡用于独立信息，折叠卡用于低频说明；不为每段文字额外套卡。
- 主题主色用于选中和主要操作，类型色用于任务类别，错误色只用于错误、风险与危险操作。
- 背景色与前景色必须成对使用；禁止页面自行叠加无规范的主色透明度制造新层级。
- 同一操作组突出一个主要操作；次要操作使用 OutlinedButton 或 TextButton。危险操作独立使用错误色。
- 常规点击区域至少 48dp；密集网格可压缩视觉内容，但必须保留可点击详情入口。
- 展开、切换与返回使用短动效。8.1.0 起时长统一由 `MotionSpec` 定义并按语义分档：进入 240ms、退出 170ms、位移（页签平移／子页推入）260ms、底栏形变 260ms、副页跨页签 320ms、轻反馈 180ms；全部经「设置 → 外观 → 动画速度」倍率换算，速度设为「关闭」时退化为瞬时。新增动效必须走 `MotionSpec`，不得硬编码时长或缓动。只记住用户主动选择的视图，不保存临时提示或弹窗状态。

### 顶部状态聚合器

- 生活阶段、当前精力、出行方式等高频小调整集中在页面标题后的单一“今日状态”入口；不得各自在页面不同位置长期占用一张卡片。
- 收起态只显示一行可读摘要和“调整”入口，不横排多个开关；整行点击区域均可展开，常规高度不得低于 48dp。
- 展开态按“生活阶段 → 精力 → 校园／出行”的稳定顺序纵向排列；选项可横向滚动，窄屏和大字体下不得压缩成不可读按钮。
- 展开使用 `MotionSpec.quick()` 的顶部展开并淡入，收起用退出档（更短）；遵循系统减少动画设置。折叠状态属于临时界面状态，离开页面后不持久化。
- 顶部聚合器只承载当天经常调整或需要随时看见的状态。默认时长、地点库、提醒规则等长期参数仍进入设置；不得为了集中入口复制同一设置。
- 摘要必须说明当前真实值或“待更新”，不能把默认值显示成今日状态。关闭某项能力时，摘要显示关闭状态并隐藏无效的下级选项。

### 滚动条与加载条

- 页面滚动条只表达当前位置，不成为独立装饰：内容不可滚动时隐藏，滚动中增强，停止后保留低对比提示。
- 滚动条使用主题 `onSurfaceVariant` 派生颜色；页面不得写死灰色或为同一纵向容器叠加第二条轨迹。
- 整页、弹窗和横向筛选各自只处理自己的滚动方向；横向内容优先通过裁切与手势反馈表达，不增加常驻粗轨迹。
- 无法估算完成比例的联网或读取操作使用统一不确定加载条；能够计算完成度的目标等使用确定进度条。
- 加载只阻塞真实相关区域。短操作不闪烁进度条，错误状态必须由明确文案承接，不能让静止加载条代替失败提示。
- 线性条统一使用主题主色、`surfaceVariant` 轨道和完整圆角；全局加载为 4dp，内容进度默认 6dp。

### 分类切换与批量管理

- 同一页面存在三类以上并列内容时，优先在内容顶部使用单选分类条；标签附真实数量，窄屏允许横向滚动，不把多个完整区域同时展开。
- 分类切换使用短淡入或内容替换（`MotionSpec.quick()` / `move()`）；只改变查看范围，不修改数据。需要记忆时必须有明确产品理由，否则作为当前页面临时状态。
- 批量管理由标题附近的次级入口开启；进入后复用原卡片位置显示选择框，并持续显示已选数量，不另开难以返回的管理页。
- 删除等不可恢复操作必须二次确认并说明连带影响；确认按钮使用错误语义色，取消保持普通文字按钮。批量操作完成后退出选择态并清空选择。

## 逐页规则

### 今日与收集箱

- 先显示正在做什么、接下来和用户记录；解释性文字后置。
- 收集箱卡片不重复讲解安排、推进、参考和目标的完整流程。
- “删除方向”和“删除任务”必须保持可区分；已生成步骤会保留的影响不可隐去。
- 精力、活动统计等口径已有帮助承载时，不在每次出现的卡片内重复。

### 日程与课表

- 日、周、课表共享页面层级，不重复显示“固定课表／固定周课表”。
- 网格已经表达的排列方式不再用副标题解释。
- 课程名称优先、地点次之；完整星期、时间和地点通过详情查看。
- 视图切换与节次设置属于操作；收纳规则等低频说明进入帮助。

### 计划、统计与设置

- 入口摘要优先显示真实数量和状态，没有增量信息时不重复标题。
- 统计必须保留时间范围、单位和样本不足状态，数据来源细节进入帮助。
- 设置首页保留短摘要，默认值、作用和影响放入折叠说明。
- 当前功能帮助不得承诺尚未实现的未来能力。

## 验收门槛

- 相邻区域不重复表达同一信息，用户内容比解释性文字更突出。
- 被删除的必要说明可以从就近帮助或使用说明书找到。
- 按钮不挤压，文本不溢出，色块内容不过早省略。
- 深浅主题中文字可读、层级明确，不产生无规范色差。
- 自动测试通过后仍需在 OPPO / ColorOS 16 / Android 15 真机检查；候选构建不等于正式发布。
