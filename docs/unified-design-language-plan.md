# FocusFlow 统一设计语言与文本减负规范

状态：第一轮代码完成，等待自动构建与真机验收。本文是文本取舍与界面基础规则的唯一规范来源；具体完成状态以代码、CI 与真机验收为准。

## 目标与边界

- 降低界面噪声，让用户内容和下一步操作优先于产品解释。
- 统一层级、间距、组件分工和颜色语义，同时允许课表、时间轴等专业界面保留独特结构。
- 不因视觉整理改变课程、任务、提醒、统计口径或本地数据；不删除必要的风险、异常和操作影响说明。
- 完整教程集中在快速入门、使用说明书和页面帮助；常用页面只显示当前决策真正需要的信息。

## 文本取舍

| 类型 | 规则 |
| --- | --- |
| 重复标题 | 相邻区域只保留一个；控件已经明确表达的说明删除 |
| 常驻教学 | 高频操作不长期讲解，移入首次提示或帮助 |
| 默认值与影响 | 在相关设置旁保留摘要，完整内容使用折叠帮助 |
| 当前状态 | 必须准确区分未开启、未配置、暂无数据和异常 |
| 风险与异常 | 直接显示，并说明用户可采取的下一步 |
| 用户内容 | 标题、课程、任务、地点和备注优先获得空间 |
| 更新信息 | 弹窗只给真实版本号与核心变化，详情进入版本路线图 |

默认文案不得冒充实时状态；动态值不得写死为默认值。按钮、帮助路径、设置名称和实际行为必须一致。

## 基础视觉规则

- 字体层级：页面标题使用 `displaySmall`；区域标题使用 `titleLarge/titleMedium`；正文使用 `bodyMedium/bodySmall`；辅助信息使用 `labelMedium/labelSmall`。
- 间距只从 4、8、12、16、24dp 中选用；普通页面水平边距以 16dp 为基准。
- 页面只保留一个主标题。入口卡用于导航，内容卡用于独立信息，折叠卡用于低频说明；不为每段文字额外套卡。
- 主题主色用于选中和主要操作，类型色用于任务类别，错误色只用于错误、风险与危险操作。
- 背景色与前景色必须成对使用；禁止页面自行叠加无规范的主色透明度制造新层级。
- 同一操作组突出一个主要操作；次要操作使用 OutlinedButton 或 TextButton。危险操作独立使用错误色。
- 常规点击区域至少 48dp；密集网格可压缩视觉内容，但必须保留可点击详情入口。
- 展开、切换与返回使用 150–250ms 的短动效。只记住用户主动选择的视图，不保存临时提示或弹窗状态。

## 逐页规则

### 今日与收集箱

- 先显示正在做什么、接下来和用户记录；解释性文字后置。
- 收集箱卡片不重复讲解安排、推进、参考和目标的完整流程。
- “删除方向”和“删除任务”必须保持可区分；已生成步骤会保留的影响不可隐去。
- 精力、活动统计等口径已有帮助承载时，不在每次出现的卡片内重复。

### 日程与课表

- 日、周、课表共享页面层级，不重复显示“固定课表／固定周课表”。
- 网格已经表达的排列方式不再用副标题解释。
- 课程名称优先、地点次之；完整星期、时间和地点通过详情查看。
- 视图切换与节次设置属于操作；收纳规则等低频说明进入帮助。

### 计划、统计与设置

- 入口摘要优先显示真实数量和状态，没有增量信息时不重复标题。
- 统计必须保留时间范围、单位和样本不足状态，数据来源细节进入帮助。
- 设置首页保留短摘要，默认值、作用和影响放入折叠说明。
- 当前功能帮助不得承诺尚未实现的未来能力。

## 验收门槛

- 相邻区域不重复表达同一信息，用户内容比解释性文字更突出。
- 被删除的必要说明可以从就近帮助或使用说明书找到。
- 按钮不挤压，文本不溢出，色块内容不过早省略。
- 深浅主题中文字可读、层级明确，不产生无规范色差。
- 自动测试通过后仍需在 OPPO / ColorOS 16 / Android 15 真机检查；候选构建不等于正式发布。
