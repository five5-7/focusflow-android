# FocusFlow 统一设计语言计划

状态：后续独立版本候选，不纳入 7.4.0。

## 范围

- 设计令牌：六色主题角色、文字层级、4/8 点间距网格、圆角、描边、阴影与动画时长。
- 核心组件：页面标题、信息卡、任务卡、设置行、折叠区、按钮、Chip、弹窗、空状态及悬浮导航统一状态规范。
- 导航与转场：主页面切换、进入子页面、返回、弹窗和系统返回采用一致层级语义，并支持系统“减少动画”。
- 屏幕适配：状态栏和挖孔安全区、手势条与三键导航、普通屏、全面屏、窄屏、横屏和大字体。
- 主题适配：每套主题明确导航栏色、选中容器色、内容色和对比度；深色模式不复用不合适的浅色表面。

## 实施顺序

1. 盘点当前所有颜色、尺寸和重复组件，建立视觉回归基线。
2. 先引入令牌和公共组件，不同时改变信息架构。
3. 依次迁移底栏、四个主页面、子页面、弹窗和通知相关设置。
4. 用截图对比验证五套主题、深浅模式、字体缩放和两类系统导航。

## 发布门槛

- 不再出现选中色块与悬浮底栏边界冲突、主题切换后底栏不变色或正文被状态栏截断。
- 所有交互状态具备默认、按下、选中、禁用和焦点表现。
- 页面迁移期间功能和数据结构保持不变；视觉重构使用独立版本与独立真机验收。
