# FocusFlow 7.2.0 候选验收清单

7.2.0 只有在自动测试、覆盖安装和 OPPO/ColorOS 后台实测均通过后才可标记稳定发布。

## 覆盖安装与数据

- 从 7.1.3/7.1.4 直接覆盖安装，不卸载。
- 原有任务、日程、改期、主题、课程、活动和历史记录完整。
- 设置页显示 7.2.0；应用重启和手机重启后无闪退。

## 每日精力询问

- 新安装默认关闭；今日页显示未开启说明和开启入口。
- 开启后设置页显示下一次预计时间；修改小时后时间随之更新。
- 点击“一分钟测试”，锁屏或切到后台等待，通知应送达；返回设置页显示“已送达”。
- 分别验证通知权限关闭、一次性静音、免打扰、活动进行中、今日已记录与延迟超过两小时，最近结果应准确且不会伪装为已送达。
- 有至少三次签到时只显示建议；不点击“采纳”不得自动改动询问时间。

## 吃饭提醒

- 新安装饭点提醒默认关闭；覆盖安装保留用户已有明确选择。
- 关闭时三餐均无后台通知；开启后只在当天合理窗口提醒。
- “用餐结束询问”默认关闭：确认开始后不出现“吃完了吗”，且没有未结束用餐记录。
- 开启结束询问后，确认开始会按预计时长追问；关闭该子开关立即撤销结束提醒，但保留饭点提醒。
- 关闭总开关同时撤销饭点和结束提醒；假期可保持关闭且不影响其他日程提醒。

## 前台应用检测

- 默认关闭；游戏、视频到点仍收到通用提醒。
- 开启但未授予使用情况访问时仍收到通用提醒，设置页显示“未授予”。
- 授权并将应用正确分类后，持续停留超过两分钟，到点文案应包含实际应用名；十分钟后仅在仍可靠匹配时复查。
- 切换到其他应用或系统无法识别时，不得自动结束活动，不得写入实际结束时间；设置页应显示“其他应用”或“未能可靠识别”。
- 删除或改期活动后旧广播不得弹出；通知“结束／延长 15 分钟”只作用于当前计划。

## 通知与稳定性回归

- OPPO/ColorOS 16：允许通知、自启动、后台运行并关闭不必要的省电限制后，锁屏测试精力、饭点、任务和活动提醒。
- 系统重启后未来提醒恢复；关闭任一开关后旧闹钟不再出现。
- 深色模式、大字体、三键导航和全面屏下设置文案、按钮与底栏无截断。
- 连续使用至少一天，记录漏发、重复、延迟、错误文案和闪退的准确时间及操作顺序。
