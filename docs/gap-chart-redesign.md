# 空挡图局部设计稿

状态：展示原型已通过 rc.2 自动构建；rc.3 补齐有课日的课前自由时段，等待自动构建与真机验收。

## 布局决定

- 七天横排，时间纵向：使用同一连续时间轴比较空挡在一天中的位置。
- 默认覆盖 08:00–22:00；数据超出时按整点扩展，不能裁掉早晚空挡。
- 图高 336dp，按真实分钟映射色块高度；短空挡不人为加高，避免误表达时长。
- 课间使用主题 primary，自由时段使用 tertiary，图例同时给出文字。
- 色块内不塞课程名、时间或分钟数。选择星期后，下方列出当天完整起止、类型和分钟数。
- 默认选择今天；星期标题和整列均可切换，明细不截断；不新增持久化设置。
- 留白只表示没有展示的可用区间，不宣称该处一定已占用。
- 保留原有分类与数据，不新增排入操作，不处理历史清空入口。自由时段生成补齐第一节课前的区间；课间仍由通勤感知算法单独生成，避免重复。
