## 代码逻辑复核边界

核心数据源在进程中只选一次，Room 激活仍关闭；Legacy 和 Room Repository 继续使用既有写入/CAS/恢复日志边界。损坏原串备份失败时的只读保护、课程合并/拆分/恢复和重复规则恢复不重写，交由已有回归套件验证。提醒注册/取消/恢复、旧广播校验、权限与免打扰策略保持。课程身份持久化已有自动覆盖，但显示层仍需维护者复核。

本次审计针对上述关键路径，不等于逐行证明整个应用无缺陷。自动测试不能证明厂商通知必达、图片背景视觉质量或冷启动帧率。当前没有新候选的一天正常使用、Keystore 失效/换机恢复或最新 UI 的完整设备证据。
