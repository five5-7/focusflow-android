## 只观察本轮变化

1. 默认和较大字号下打开新增待办，重复选项尤其“有课日”完整，日期选项不挤压。抽查编辑、安排、改期中的优先级/时间/冲突操作，空间不足时换行且可点；不必保存测试数据。
2. 今日收集箱有内容时，“查看全部”在标题右侧同行，点开仍进入完整列表。
3. 底栏左右和底部在系统安全区内等距留白，比旧包更宽；有页面历史时观察两侧箭头外移、返回/折返和长按历史，触控不贴边；弹窗和键盘操作正常。普通屏幕单边拓宽8dp，箭头实际外移4dp；窄屏/大字号单边拓宽2dp，箭头外移2dp。
4. 桌面图标保留原聚焦框与F，渐变/阴影/高光有层次，系统裁切无缺口；主题单色轮廓保持。
