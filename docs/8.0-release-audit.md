# FocusFlow 8.0 正式版发布审计

状态：真机验收完成，正式版构建中。本文保留发布范围与门槛记录。

## 已核对的基础

- 代码基线：7.9 至 7.12 的改动连续叠加在 PR #42；正式版为 `8.0.0` / versionCode 511。
- 自动证据：Run 297、8.0 rc.1 的 Run 298、rc.2 的 Run 300 与 rc.3 的 Run 303 均通过版本元数据、单元测试、Debug/Release 构建、稳定签名和 APK 元数据校验；维护者已确认 rc.3 真机验收完成。
- 上一个正式 Release 是 7.1.3；8.0.0 只有在正式版提交通过独立 CI、合并并建立 GitHub Release 后才完成发布。
- 7.4、7.9 至 7.12 的历史候选说明不能各自被单独发布；8.0 必须以最终整合候选为唯一来源。

## 8.0 可收束的已实现内容

1. 日常使用与提醒：7.2 至 7.4 的保守提醒、精力采样、活动生命周期和后台诊断。
2. 收集箱与计划：7.5 的待整理／推进／参考流转，任务恢复与历史记录。
3. 课程与通勤：固定课表、节次表、地点、课程生效期、启停、单删/批删和通勤档位。
4. 校园生活边界：首次选择、关闭后不删数据、入口提示、当前位置空状态、电动车电量。
5. 视觉与数据治理：统一设计语言、顶部今日状态、收集箱筛选、空挡分类与图、历史删除与统计重算。

## 不纳入 8.0

- 单次安排时覆盖通勤耗时。
- 真正仅当天有效的交通方式／电动车状态。
- 新的地图 SDK、云同步、桌面小组件、通用表格识别。

这些是后续独立功能，不能为了“凑正式版”改变已经通过构建的排程和数据边界。
