## 工程核验与发布路径

必须使用正式版本源码完整运行 Debug/Release 单元测试、双 APK 构建、Room schema、版本元数据、稳定签名和不可调试检查。正式发布脚本再次解析逐份 XML 并对齐 CI summary，核对实际 APK SHA-256、包名、581/9.0.0、证书及 main 精确提交；四份 Release 资产核对远端摘要后才将草稿转为公开正式 Release。

旧 8.2.0/8.2.1 版本绑定的发布器保留手动恢复入口，停止对新 main 构建自动运行。9.0 发布器绑定成功的 main 构建与源码提交，禁止复用旧候选的工程通过记录。

**当前结果：待正式版 CI、主分支构建及公开 Release 实际完成后记录。**
