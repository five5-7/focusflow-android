## 结论

**小提交②已有实际行为实现，但本次复审暂不通过。** 两阶段登录、从真实 option 选取 value、同一会话请求、取消和旋转期间的状态保留均已进入代码；下面三项涉及无效会话重试、超时会话滞留和密码清零时点，需修正后再审。另有一项请求／响应一致性尚不能从本包证实，应补合成反例或提供提交①的解析器实现。

### 1. 已失效会话被当作可重试，重复请求无法成功（阻断）

`ZjuTimetableClient.kt:516-532` 对所有 `ZjuTimetableParser.parse(...)` 失败都返回 `ConfirmAttempt(..., sessionUsable = true)`；随后 `:243-247` 将句柄放回。解析器明确存在“教务登录已失效，请重新完成统一身份认证”和验证码失败；本包的 `ZjuTimetableSessionTest.an expired timetable session reports the parser message` 已构造服务器返回登录页，却只断言了**第一次**的文案，未断言句柄状态。当前失败页仍保留原学期选项，主要按钮继续是“导入所选学期”；再点会以同一失效 Cookie 发相同 POST，无法靠重试恢复。

修正：给不可恢复的解析失败一个**结构化原因**，至少登录已失效应作废句柄并中断本次会话，让 UI 清掉旧选项、展示重新登录动作；验证码等需重新认证的情况按真实会话能力分类。暂时性网络异常仍可在会话尚有效时重试。不要通过匹配中文错误文案判断重试策略。用“登录页返回后再次点击不会再 POST，重新登录取得新选项后可以查询”作可证伪测试，并核失败提示和按钮一致。

### 2. 十分钟过期只在再次调用时清理，超时条目可一直留在静态表中（阻断）

`ZjuTimetableClient.kt:98,148,190-213,338-343`：`pendingSessions` 是进程级表。`purgeExpiredSessions()` 仅在下一次 `beginSession()` 执行；`confirmSelectedSemester()` 仅在用户点击时发现过期，而且直接移除句柄后返回，没有调用 `transport.cancel()`。如果用户读取学期选项后把页面留在前台／后台而不操作，十分钟到了也不会清掉已认证 Cookie、账号和句柄。README 的“10 分钟 TTL 兜底、不会永久滞留”和第四次审定的“超时要废弃会话”因此均未成立。

修正：在创建会话时安排与该句柄绑定的到期清理（或同等可靠的超时取消机制）；到期原子移除并取消传输，UI 失效选项、提示重新登录。到期时若确认请求已经在途，明确继续或取消规则并覆盖测试；时钟回拨时仍应有有限寿命。测试需在**没有第二次 begin/confirm 调用**的条件下模拟到期，断言服务端会话被取消、句柄失效且选项不再能导入。避免每个会话创建一个永久线程。

### 3. 认证已完成后密码数组仍留到首页读取结束（阻断）

`ZjuTimetableClient.kt:155-173,450-476`（第一阶段线程 finally 与登录后读首页路径）：UI 点击后立即清空输入框，但传入客户端的 `CharArray` 直到 `beginSessionBlocking()` **全部返回**才在 finally 清零。成功进入教务系统后还要 GET 首页并读全部 option；该请求有 40 秒总超时，在等待期间原密码数组仍保留。这不符合第四次审定“认证密码在登录请求结束后立即从 UI 和传入的 `CharArray` 清除”。

修正：CAS 登录提交后无论认证成功或失败，确认后续再不需要明文密码时就立即清零输入数组，同时保留外层 finally 兜底；不得把密码放入待确认会话。合成测试让首页 `GET` 用 latch 阻塞，等待其已进入后检查调用方所持 `CharArray` 全为 `\u0000`，再释放请求；只在整个 `beginSession` 回调后检查清零不足以发现这条缺陷。

### 4. 服务器静默返回别的学年尚未被本包排除（需核实）

`ZjuTimetableClient.kt:504-520` 把带用户所选 value 的请求送出后，只根据 `ZjuTimetableParser.parse(payload, year.value, term.value)` 的成功与否返回 Success。本次只附小提交②的 diff，未附小提交①及新版解析器的完整实现，因此**不能断言**解析器会核对响应回显。先前脱敏样本证实响应 `xnm` 为完整学年、`xqm` 为单字显示；如果教务对不支持的学年／学期组合静默返回当前课表，即使请求值来自首页选项，仍可能给错误课表贴上所选学期标签。

请附“请求 `2026-2027 / 1|秋`、合成响应回显 `2025-2026 / 秋`”的测试及执行结果：必须报不一致、不得返回可导入 Success。`xqm` 的单字回显无法区分 `1|短`／`2|短`，因此对短学期只能核对可证实的显示部分，不能声称已从响应证明完整代码。若解析器在提交①已经完成核对，指出实现位置即可；否则作为同一范围的行为修正补上。
