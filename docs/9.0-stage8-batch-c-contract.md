# 阶段 8 批次 C：预览审核与确认边界

日期：2026-10-01。范围是把批次 B 的几何预览交给用户逐项审核；不改变现有 CourseImportBatch/Policy，不直接写 Room。

## 已实现

- `VisionReviewUi.kt` 提供 Compose 审核对话框和四角人工锚点编辑控件；它只收集用户决定，不绕过后续确认策略。
- `VisionReviewDecision` 支持明确的确认、编辑、拒绝三种决定。
- 确认/编辑只能在候选具有完整且合法的星期与节次时标记 `CONFIRMED_BY_USER`。
- 缺失坐标、非法编辑、重复决定保持 `NEEDS_REVIEW` 并产生告警。
- 拒绝是显式状态；未知候选决定不会创建候选。
- `VisionReviewResult` 返回审核后的候选、未解决 ID 与告警，由上层继续进入既有待确认导入流程。

## 边界

审核 UI 与纯 Kotlin 决策适配器已经接入，但不包含 OCR、网络重试、Room 写入或自动确认。用户未决定的候选不得进入确认状态；真实图片、设备交互、取消路径和 UI 可用性仍需单独验收。
