## FocusFlow 8.2.1 · 亚克力与毛玻璃扩展

这是 8.2.0 可选外观系统的修订版，正式版 versionCode 534。

### 主要变化

- 卡片材质新增亚克力与毛玻璃；亚克力保留更多背景轮廓且不画独立描边，毛玻璃使用更强扩散并保留沿真实圆角闭合的亮边。
- 悬浮底栏与页内弹窗可按实际位置透出并模糊被遮住的日程内容，文字、按钮和导航图标保持清晰。
- 修复玻璃卡片叠加 elevation、计划页卡片边缘冲突以及一次导致页面无法上下滑动的模糊实现回归。
- 修正图片背景不透明度的方向与玻璃采样关系，100% 表示图片最明显，不再出现 50% 反而更实的反直觉表现。
- 页面背景与课表底图新增非破坏性图片取景：可调整横向焦点、纵向焦点与 1–4× 缩放；原图保留在本机，不因取景被破坏。
- 丰富外观仍默认关闭；关闭时不创建相关捕获层，旧设置和主题预设继续兼容。

### 验证

- 8.2.1-rc.8 的 GitHub Actions Run 361 全部门禁通过。
- 正式版重新增加 versionCode，并在 main 上重新执行 debug/release 单测、稳定签名 APK 构建、签名与版本元数据校验。

### 安装

支持 Android 8.0（API 26）及以上。可直接覆盖安装已有 8.2.0 或 8.2.1 候选版，不需要清除数据。
