# rc.40 今日页 UI 快速验收

范围：experiment/ui-polish，8.3.0-rc.40 / versionCode 574。只测 UI，不构造课表、识别、提醒或持久化数据。

## 最短路径

1. 用稳定签名 APK 执行 `adb install -r` 覆盖安装；不要卸载、清数据或换签名。先记录原外观、动画速度、深色、字号、背景、卡片材质和课程/任务数量。
2. 用 `adb shell dumpsys package com.sakata.focusflow` 确认 versionName=8.3.0-rc.40、versionCode=574。
3. “今日”页检查：
   - 课程与固定安排：数量独立显示；每条记录左侧有时间标签，右侧有课程名和节次/地点；
   - 今天已安排：任务同样按时间与内容分层，点击任务仍进入日程；
   - 明天预览：时间标签可读，仍只显示前两条和真实剩余数量；
   - 收集箱：空态仍有标题和数量；有记录时查看全部、展开/收起条目。
4. 点击“今日状态 → 调整 → 收起”三次，确认整行可点、内容从顶部展开、箭头旋转并复位，无残留空白。
5. 有可整理记录时，点击收集箱“整理多项”，勾选/取消一条，再点“完成”；确认工具栏平滑展开和收回，不点击删除或改动数据。
6. 有可整理任务时，点击“整理多项”，再点“完成整理”；确认卡片高度平滑变化，列表不重叠。
7. 设置 → 外观：直接点当前“设置”导航返回，确认保留收回动画且背景不闪；快速记录弹出键盘时底栏保持底部。
8. 日程页依次切换“日 → 周 → 课表 → 日”；确认内容和高度平滑变化，没有旧内容叠加。

## 动画设置

- 标准：以上展开和切换有连续过渡。
- 关闭：箭头、工具栏、卡片高度和日程内容立即到位，不残留默认动画。
- 较慢：过渡明显变慢；连续快速切换后最终停在最后选择。
- 深色、大字体 1.3：时间标签、数量徽标、箭头和长标题可读，内容可滚到底部。
- 测试后恢复原设置；输入后先收起 IME 再 dump UI。每条结果写“通过 / 失败 / 未执行”，附截图或 XML 路径。
