日期：2026-10-01。基线 `ae8c6e39f9661974623393ae250fa47d61da8cbb`。范围为 8.1–8.4；新网格识别、人工锚点和图片修正预览属于批次 B。Room 激活保持关闭，不更改 schema。

## 用户路径

设置 → 高级工具 → 课表识别：开启可选功能，保存名称、HTTPS 接口根地址、视觉模型和 key；点击能力测试，三个必要能力通过后可设默认。截图导入仍须显式选择上传服务，再打开系统文件选择器。取消、超时或配置变化后的旧结果不写课程；成功结果经过现有 CourseImportBatch/Policy 进入待确认，未经确认不安排课程闹钟。没有后台探测、自动改用另一供应商或新协议依赖。

仅实现 OpenAI 兼容 Chat Completions 非流式协议。根地址保留用户路径前缀及已有 v1，追加 chat/completions 或 models；不自动猜测协议。GET models 可失败，用户可以手填模型。HTTP 3xx 一律拒绝，Authorization 不随重定向发送。课程数组内部解析沿用旧实现，其宽松数字/围栏处理到 8.6 再替换；HTTP 外层 JSON 已严格检查完整输入、重复键、深度、UTF-8 与字节上限。

## 配置与凭据

- profile 只保存身份、名称、根地址、模型、协议、超时、credentialRef、配置修订和成功能力绑定；无原始 key。变更配置产生新 revision，变更 key 产生新凭据 revision，旧能力记录不可用于默认或导入。
- 能力测试使用本机生成的六位随机数字 JPEG，答案不在提示词内。连接、图像金标匹配、严格 JSON 三项分别保存，并绑定配置/凭据修订、探测版本与时间。HTTP 200 或 models 列表可读都不能证明支持图像。测试失败会撤销该配置的可用验证。
- AndroidKeyStore 生成 AES-256/GCM 密钥，API key 加密后写 `focusflow_credentials.xml`。专门排除该文件的云备份/设备迁移，业务 SharedPreferences 继续备份。换机或密钥失效要求重填，不清除课程。内存中仍需解密使用，不承诺内存绝无明文。
- 旧 siliconflow_api_key 先确认密文 commit 成功并可解密，再确认删除旧明文。学习建议读取同一个共享 credentialRef；启用状态和用户模型不被自动打开/替换。失败提交跨 store 实例保留同进程不确定守卫，普通读回不能证明落盘；明确重试的成功提交才解除。中断后按实际记录继续。两把旧/新 key 不一致时拒绝静默覆盖。
- 已存 key 不回填到编辑框；只有显式保存替换/删除操作改动凭据。删除共享 key 会影响学习建议与视觉服务。删除硅基流动 profile 保留共享凭据，学习建议仍可用。删除独立服务之前可显式删除它的 key；profile 删除不隐式删除密文，以免失败后丢失凭据。
- 共享旧凭据只允许内置硅基流动地址；其它供应商须新增独立服务并填写自己的 key。AI 周总结的独立旧 key、地图 key 等不属于本次迁移范围，不宣称全应用所有 key 已加密。过去生成的备份无法追回。
- 配置损坏保留原文，不解释为空列表；失败 commit 返回未确认，不以进程内状态报保存成功。配置有专门的重试确认入口。

## 固定预算与候选契约

| 项 | 上限 |
| --- | --- |
| 单会话总时限 | 120 秒（含所有请求和重试） |
| 请求总数 / 并发 | 8 / 2 |
| 单图 JPEG | 4 MiB |
| 请求体 / 响应体 | 6 MiB / 1 MiB（实际 UTF-8 字节） |
| 单次候选 | 200 |
| 服务配置 | 20 个；名称 80 字、模型 ID 200 字 |
| 配置 JSON / JSON 深度 | 128 KiB / 32 |
| 单个 key | 8192 字；不含 CR/LF |
| 单请求连接 / 响应等待 | 15 秒 / 用户设定 5–120 秒，并受总时限约束 |

会话具有随机稳定任务 ID；取消使状态永久失效，断开所有活动连接。定时器在会话截止时断开连接；仍由读循环检查预算。请求失败不输出供应商原始错误、Authorization、图片或响应正文，不重试/换供应商。

VisionBox 为原图归一化框；VisionImageGeometry 明确尺寸、3×3 变换、星期/节次轴及 detected/manual 证据；VisionCandidate 包含原文地点、未知坐标/周次、笔记与文字/几何置信度。未知用 null，不能成为第 1 节；只有用户确认且坐标齐全才能标为 CONFIRMED_BY_USER。上述 DTO 是批次 B 的契约，不代表当前已执行网格定位，更不是新 Room 实体。

## 合成金标与验证边界

`tools/generate_vision_samples.py` 可重建 24 份 SVG 金标及 manifest：清晰 10，可修复 6，人工锚点 4，拒绝 4。每份保存文件 SHA-256、尺寸、变换、原图框/角点、课程文字、可信/未知坐标与期望处置。覆盖跨行块、不同星期、末节、备注、缩放、旋转、弱网格、摩尔纹、缺表头/节次及非课表。透视组当前为可控仿射倾斜，真实项目变换与拍屏照片需批次 B 补齐；不冒充完整透视识别验证。

这些测试验证 DTO、标注及语料完整性，不是实际 OCR/视觉模型识别结果。没有用户私人图片。两个真实供应商、真实 Android Keystore、换机恢复、设备取消/UI 和真实图片识别仍需独立验收，不继承阶段 7 的真机跳过决定。
