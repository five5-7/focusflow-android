## 2. 不透明度的实测代码范围与 9.0 契约

| 对象 | 当前可调范围/面层数值 | 9.0 处理 |
| --- | --- | --- |
| 页面图片自身 | `backdropOpacity` 0–100%，默认 100%；其上有基础 34%、按图片亮度最多 75% 的主题遮罩 | 保持现有 0–100% 与遮罩行为；不把“图片自身 100%”误记为玻璃卡面的可调上限 |
| 课表/日程图片自身 | `timetableOpacity` 0–100%，默认 100%；底板另有格线/文本保护 | 保持原键、裁剪和 0–100%，不调整课程/事件块原色 |
| 亚克力卡片/弹窗/底栏染色面层 | `acrylicStops` 固定 alpha 0.60，另有 Haze tint 0.10；UI 没有玻璃卡面不透明度控件 | 增加共享的“玻璃卡面不透明度”；未配置仍用原 60% |
| 毛玻璃卡片/弹窗/底栏染色面层 | `frostedStops` 固定 alpha 0.48，另有 Haze tint 0.07 与独立亮边；UI 没有玻璃卡面不透明度控件 | 同一控件、同一上限；未配置仍用原 48%，保留毛玻璃亮边和较大模糊半径 |
| 页面/日程普通半透明色块 | `TodayScreen`、`ScheduleTimelineUi` 等在调用处以 0.10–0.88 等 alpha 标记用途；弹窗遮罩 0.32 | 这些数值表达状态/事件类型或遮罩，不随用户玻璃卡面不透明度全局放大 |

**数值决定：玻璃材质染色面层的用户可调范围冻结为 40%–95%。** 上限 95% 高于现有亚克力的 60% 和毛玻璃的 48%，仍留下至少 5% 的面层透视；这只是染色画刷的 alpha，不等于整个控件的合成不透明度（Haze tint、模糊源和边缘高光也参与合成）。文字使用主题内容色而不是跟随面层降低 alpha。若 OPPO 真机发现 95% 下材质特征或层级丢失，按测试证据改上限并更新此契约，不宣称已完成真机验收。

下一实现检查点在 `AppearanceSpec` 增加一个**可缺省**的共享玻璃卡面值；旧设置和旧预设缺少新键时继续以材质各自的 60%/48% 绘制。显式滑动后卡片、弹窗和底栏从同一归一化值生成画刷。将值加入现有外观保存、主题预设编解码、预览与恢复默认流程，不重写旧键；渲染状态变化时使 `remember` 的画刷缓存随值失效。背景图片和课表图片仍由各自已有的 0–100% 控件管理。测试至少覆盖缺省保持、范围夹取、预设往返、95% 画刷、深浅主题、完整形状裁剪和底栏渐变绘制倍率；对比度测试在 40/60/95% 与极端黑白图片背景下覆盖所有主题，正文最低 4.5:1，关键小字/格线要另做可读性与真机判定。

## 3. 覆盖矩阵和低保真交互

统一检查维度：页背景 `跟随主题 / 渐变 / 固定色 / 图片`，卡材质 `默认 / 渐变 / 柔光 / 亚克力 / 毛玻璃`，浅/深主题、正常/最大卡面值，以及普通/展开/选择/禁用/加载状态。课表底板另外覆盖 `透明 / 选色 / 图片`；系统“移除动画”、应用动画关闭、丰富效果关闭要分别核对。以各行入口为边界检查同类状态，不能只在五个示例页面过关。

| 场景 | 窄屏/大字/键盘 | 动效与内容状态 | 主要材质断点 |
| --- | --- | --- | --- |
| 今日与全局加号 | 标题超长、菜单回流、输入聚焦 | 从捕捉到安排的打开/关闭；未来移除首页“自由开始活动”面板 | 新旧弹窗入口一致；按钮不会盖住输入 |
| 日程与课表 | 七列/节次小字、横竖屏、课程名称溢出 | 切日、改期、查看详情、课程选择与导入加载 | 底板与块颜色独立；透明底板格线仍清楚 |
| 计划与历史 | 批量列表与长笔记 | “建模中”展开、最近事件进入/退出选择、全选/禁用删除 | 选择工具栏连续，选中态有区别，弹窗遮住文字时依旧有边界 |
| 设置与外观 | 四个高频设置的 2×2 布局、大字回流、取色预览 | 丰富效果开关、材质切换、滑块拖动、预设应用 | 预览与主界面数值一致；关闭丰富效果不删除已选值 |
| 弹窗/底栏/导入页 | 键盘抬起、横屏可用高度不足 | 首次打开弹窗、次级确认、切换材质与加载进度 | Haze 捕获失效时有可读兜底，不卡住焦点或按钮 |

低保真稿（后续仅作原型，不冻结完整页面）：

- **设置选项组**：四个等权短选项在常见手机宽度排成两行两列；字体放大或可用宽度不足时变为一列，更宽屏可排成一行。当前设置首页只有三个并列导航入口，不为凑四格添加或上移低频工具。
- **安排时间**：标题和五个模式选项置顶；模式为“未安排/仅日期/固定时间/弹性范围/重复”，正文只显示当前模式字段；底部操作始终可见。输入聚焦时收起说明与非必要选项；键盘关闭后恢复已填字段，改变模式不丢草稿。
- **历史批量管理**：标题区切换选择状态，显示“已选数/全选/删除”；条目选中状态与工具栏同步过渡，删除确认只作用于当前选中 ID；空选择时删除禁用。

## 6. 玻璃卡面上限实现检查点

2026-09-23 在本分支实施共享玻璃面层设置：`AppearanceSpec.glassSurfaceOpacity` 缺省表示未手动调节；可调 40–95%，统一用于 `materialBrush` 生成的亚克力/毛玻璃画刷。`FocusCard` 的卡片面层以及 `surfaceMaterialFill` 的弹窗/底栏从同一个 `LocalAppearance` 取值，`remember` 包含这个值，拖动滑块时能更新缓存。底栏跟随页面渐变时原有倍率仅用于非玻璃材质，玻璃继续由自身 alpha 表达；背景图片及课表底图的原有 0–100% 滑块不变。

设置 → 外观和自定义主题编辑器共用 `CardMaterialControls`；仅选中亚克力或毛玻璃且丰富效果开启时显示玻璃卡面滑块。原设置缺少新键时，亚克力仍绘制 60%、毛玻璃仍绘制 48%；恢复默认删除新键。旧主题预设不增加新字段，新预设仅在用户主动调节后记入 `glassSurfaceOpacity`。已有 `appearance_*` 键不改名，8.3.0-rc.12 / 546 与 Room 产品激活关闭状态不变。

自动验证覆盖旧设置读取及保存、显示默认、显式保存/夹取/恢复默认、损坏新键、旧/新预设往返，及两种玻璃面层在 40/60/95% 的生成与完整内描边规则。针对所有内置主题的明暗模式、纯黑/纯白背景图和 0/50/100% 图片强度，测试通过页面遮罩/Haze 染色与玻璃画刷近似合成计算正文对比度。Run 445 发现测试容差小于 Compose 的 8 位 alpha 量化误差（48% 实际表示为 122/255），调整断言精度后 Run 446 的双变体单测、Room schema、Debug/Release 构建、签名与版本核验及产物上传全部通过。实现的本地提交 `2321a598db267453f62e94e9e7e589c3a28db6b2` 与远端提交 `0f5aaeb592acf1aaab9eca2364846d22936176cb` 的内容树同为 `145246516452b04494f0bd2a8caa9f1a91fdab1c`。

真机验收仍需在 OPPO Find X8 Ultra 上完成：在丰富效果开启且分别选亚克力/毛玻璃时，核对初始 60%/48% 与手动调至 40%、95% 的卡片、弹窗、底栏和主题预设预览；以跟随主题、渐变、固定色、黑白或高对比图片背景检查正文和边界，切换主题/页面时观察画刷即时更新；关闭丰富效果与恢复默认后核对保存值/缺省行为；用同条件 `dumpsys gfxinfo framestats` 对比首次弹窗、页签切换和滚动重帧率。真实模糊、噪点、下方内容色块和整体层级尚未真机验收，95% 上限仍可能根据证据调整。此提交未发布，PR #51 保持草稿。
