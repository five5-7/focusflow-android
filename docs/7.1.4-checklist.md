# FocusFlow 7.1.4 候选验收

版本：`7.1.4` / versionCode `479`。7.1.3 仍是当前正式版；本候选未经验收不得替换正式 Release。

## 自动门槛

- [ ] debug、release 两套单元测试全部通过，无失败、错误或跳过。
- [ ] debug 编译和稳定签名 release APK 构建通过；release 不可调试，签名与 7.1.3 一致。
- [ ] APK 内版本为 7.1.4 / 479，覆盖安装不清除 SharedPreferences、任务、历史、主题或权限设置。

## 六类开始提醒

逐项安排游戏、视频、学习、休息、运动、自定义活动，开启“到点提醒开始”。

- [ ] 标题均为“活动开始 · 活动名”，正文分别显示实际类别；自定义显示“活动安排时间到了”。
- [ ] 学习、休息、运动和自定义通知不出现“游戏”或“娱乐”。
- [ ] 通知送达前后，“状态询问”的记录数量不变；只有用户主动签到才新增状态。
- [ ] 删除活动后等待原开始时间，不出现通知。

## 改期与离开日程

- [ ] 活动改期后在日程中仍显示为活动；旧开始／结束时间不提醒，新时间正常提醒。
- [ ] 连续改期两次只保留最后一次时间的提醒。
- [ ] 分别执行放回收集箱、缩短、暂停、放弃、删除、转为目标、归入目标，原开始／结束时间均不再提醒。
- [ ] 上述操作不误删其他活动会话或其他任务提醒。

## 收尾与前台检测

- [ ] 学习、休息、运动、自定义到点只收到一次普通收尾提醒，可结束或延长 15 分钟。
- [ ] 游戏／视频关闭前台检测或未授权使用情况访问时，只收到一次普通收尾提醒。
- [ ] 游戏／视频已授权且仍在匹配应用时收到检测说明，10 分钟后仍在使用才复查；已离开时自动按时结束且不再提醒。
- [ ] 延长 15 分钟后旧结束／复查广播不再弹出，新结束时间正常提醒。

## ColorOS 16 真机稳定性

- [ ] 从 7.1.3 直接覆盖安装，重启手机后未来活动提醒恢复。
- [ ] 应用退到后台、熄屏及省电模式下，开始和收尾提醒在系统允许范围内送达。
- [ ] 通知渠道显示“活动开始与收尾提醒”，没有新增重复渠道或重置用户原渠道偏好。
- [ ] 连续使用至少一天，无幽灵提醒、重复提醒、错误状态记录或闪退。
