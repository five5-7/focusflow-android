### 这一版修什么

8.1.0 把「上一步／下一步」也当成"会关闭弹窗的页面导航"，于是弹窗的开关变成了一步独立历史：
在 计划 → 课程 里打开课程编辑弹窗后按上一步，只会把弹窗关掉、页面不动，用户预期的"回到上一个页面"反而要按两次。
本版按维护者口径重做了这条规则。

### 主要变化

- **弹窗不再是独立的一步历史**：「副页 + 弹窗 + 已填数据」算**同一个整体**，打开弹窗本身不记录历史。
  - 开着弹窗按上一步 → 回到上一个页面（例如「课程 + 编辑弹窗」→ 计划主页）。
  - 从整体状态跳到别处（管理地点／其他页／本页签主页）后再按上一步 → **整包还原**：副页、弹窗和里面已经填进去的内容一起回来。
  - 用户自己关掉弹窗（取消／返回键／点遮罩）后，历史里那些整体快照**降级**为"只有页面"：页面这一步留着，上一步不会因此多退一步。
- **弹窗光效**：卡片改用主题染色的柔和阴影（20dp）、顶面高光渐变、1px 细描边，明显浮在压暗的页面之上。真机实测卡片下沿 130px 内亮度 147.8 → 160.5 的柔和过渡。
- **页面与卡片分层**：浅色模式页面底色比卡片压深 5%（暖杏下页面 `#F2ECE8` / 卡片 `#FFFBF9`），不再"到处都是近白色"。四套主题正文对比度 15.5–15.8:1 → 13.9–14.2:1，仍远高于 WCAG AAA 的 7:1。
- **修复**：收起状态下的弹窗仍会挡住页面点击（悬浮层不再留下 pointerInput 节点）；新弹窗接管时把已收起的旧弹窗真正关掉，避免它稍后自己冒回来。
- **修复**：「回本页签主页」会把整体吃掉。A→B→A 去抖规则原本会把「课程 + 弹窗」这一步抵消掉，于是从整体状态点「计划」页签回主页后，上一步再也回不去（真机复现并定位）。现在去抖加了例外：B 上开着弹窗时不再抵消。

### 真机验证记录（OPPO ColorOS 16 / Android 15，1440×3168）

| 路径 | 期望 | 实测 |
|---|---|---|
| 课程 + 编辑弹窗 → 上一步 | 回到计划主页（弹窗不算一步） | ✅ 标题=计划、无弹窗、无输入框 |
| → 下一步 | 整包还原 | ✅ 弹窗 + `AuditCourse` 都在（视觉模型独立复述输入框内容） |
| 整体状态 → 点「设置」页签 → 上一步 | 整包还原 | ✅ 弹窗 + `AuditCourse` 都在 |
| 整体状态 → 点「计划」页签（本页签主页）→ 上一步 | 整包还原 | ✅ 修复后通过（修复前 back 不可用） |
| 点「取消」关掉弹窗 → 上一步 / 下一步 | 不回带弹窗 | ✅ 课程页回来了，弹窗没有复活 |

弹窗光效同样为真机所见：视觉模型描述「卡片下方有柔和的阴影，卡片顶部有比底部更亮的渐变，卡片边缘有一圈很细的描边」；像素扫描显示卡片下沿 130px 内亮度 147.8 → 160.5。
