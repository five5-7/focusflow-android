# 9.0 阶段 4A：今日收集箱入口

2026-09-24。rc.20 用户已验收；本检查点开始阶段 4 的今日收集箱基础入口。

今日页收集箱现在使用一张共享材质卡片。输入标题后点保存或键盘完成键，通过现有 `CoreDataRepository.replaceTasksAndAppendEvents` 将条目和 `TASK_CREATED` 事件一同写入；成功才清空输入，存储失败时保留内容。快速记录弹窗保留自然语言解析、明日任务及直接安排能力。

非空时卡片显示总数、查看全部和最近两条待整理标题；标题单行省略，点击摘要进入收集箱列表。最近顺序优先依据创建事件时间，旧数据缺少事件时沿用现有条目顺序且不推断时间。空收集箱只显示输入。相对时间仅取事件记录时间，不使用旧描述中永久固定的“刚刚”。完整列表的逐项编辑、安排和整理入口仍在列表内。

本次没有改动任务字段、旧 JSON、通知或 Room 激活。后续阶段 4A 继续完成“之前记录”、批量整理、一次性待办与列表；本入口先在 OPPO 核对窄屏/大字下输入与保存按钮、软键盘、失败保留文字、长标题省略、空/非空状态和点击进入完整列表。
