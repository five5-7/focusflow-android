## 待办一：响应式布局收尾

### 目标

让窄屏、大字号、分屏和输入法出现时，标题、操作区、页签和悬浮底栏保持可读、可点、可滚动。

### 待处理位置

1. `FocusPageHeader`  
   复核标题操作下移后的间距、顶部安全区和页面滚动起点。操作按钮不能被状态栏或首张卡片遮住。

2. `FloatingNavigationBar`  
   大字号时页签名称允许两行显示，底栏高度随内容增长；窄屏时保留横向滚动，不能把加号和四个主入口压成不可读的小区域。输入法出现时底栏继续停在物理屏幕底部。

3. 日程模式选择  
   “日 / 周 / 课表”在 1.3 和 1.5 字号下应允许横向滚动或换行，不能把“固定课表”标题挤出屏幕。

4. 今日页操作区  
   “整理多项”“完成整理”“去日程”等操作在窄屏下应使用 `FlowRow` 或纵向排列；课程和任务标题最多两行，不能覆盖时间标签。

5. 设置和外观选项  
   选项网格、滑块说明和图片取景控件需要在 1.3/1.5 字号下保持可滚动，避免横向按钮被裁切。

### 验收条件

- 物理屏幕 1440×3168、字号 1.0/1.3/1.5 下，四个主入口均能打开。
- 390dp、360dp 以及分屏可用宽度下，标题和右侧操作不重叠。
- 快速记录弹出输入法后，背景保持原屏幕比例，悬浮底栏不被输入法推到内容区域。
- 关闭输入法后，页面和底栏位置恢复，不出现背景闪帧。
- UI dump 中主要按钮存在可点击节点，底栏四个标签和加号始终可见。

建议 adb 检查：

```powershell
adb shell settings put system font_scale 1.3
adb shell wm size
adb shell uiautomator dump /sdcard/rc42-ui.xml
adb pull /sdcard/rc42-ui.xml
adb exec-out screencap -p > rc42-font130.png
```

测试结束后恢复：

```powershell
adb shell settings put system font_scale 1.0
```

## 待办二：四页视觉层级统一

### 目标

让四个主入口都遵循同一信息顺序：

页面标题 → 当前范围/状态 → 主要操作 → 内容卡片 → 次要工具。

### 页面要求

- 今日：标题后先显示“现在/接下来/收集箱”三个主要区域；数量、时间和内容保持分层，次要说明使用较弱的正文色。
- 日程：标题后显示当前视图范围，再显示“日 / 周 / 课表”切换；切换控件和范围标题需要保持同一行级关系。
- 计划：标题后保留“从结果开始”主操作卡；课程、空挡、目标和历史入口使用同一类入口卡片，摘要不超过两行。
- 设置：高频开关与外观入口留在首页；高级工具、诊断和低频维护继续放在下方或子页，减少首页信息噪音。

### 建议实现

- 继续复用 `FocusPageHeader`，不要在单页重新定义标题字号、左侧强调条或副标题颜色。
- 新增并复用一个轻量的 `FocusSectionHeader`，统一区域标题、数量徽标和右侧操作。
- 区域标题使用 `titleMedium`/粗体，卡片标题使用 `titleMedium`，摘要使用 `bodySmall`，辅助说明使用 `labelSmall`。
- 数量和状态应该放在标题附近，避免把数量埋在长句中。
- 页面背景、卡片材质、导航栏颜色继续由现有外观系统提供；本待办不新增外观开关。

### 验收条件

- 浅色、深色、图片背景、毛玻璃四种组合下，标题和卡片仍有清晰层级。
- 四页首屏都能在不滚动的情况下看见页面标题和第一项主要内容。
- 同一页面中最多保留一个高强调主按钮，其余操作使用文本按钮或次级按钮。
- 长标题、空状态和错误提示不改变卡片圆角、内边距和底栏位置。
- 层级调整不改变课程数量、提醒数量、任务状态或任何持久化字段。
