## FocusFlow 8.1.0 · 第四个正式版

> 状态：**已发布**。本包由维护者本地以稳定签名构建（证书 SHA-256 `650a17f2…`，与 CI 同一证书），
> 并已在 OPPO ColorOS 16 真机上完成验收。`release-8.1.0.yml` 里的 CI 产物锁定值待后续 run 补齐后可用于复现校验。

8.1 把 rc.1 至 rc.6 的连续候选收束为继 6.0、7.1.3、8.0.0 之后的第四个正式版。
这一版把「手感」当作一等公民：所有动效收进一套可调规范，导航与弹窗的层级关系重新梳理。

### 主要更新

- **统一动效规范**：进入 240ms／退出 170ms／位移 260ms／底栏形变 260ms／副页跨页签 320ms 集中管理，全部随「设置 → 外观 → 动画速度」四档（关闭／较快／标准／较慢）换算；关闭后所有转场瞬时完成。
- **副页深度缩放**：子页从底栏对应图标放大展开、返回时缩回同一图标并同步淡出；主页与主页之间一律左右平移（不再缩放）；深链、通知、快速记录等**直接打开**子页时照常播放放大。
- **底栏选中态**：会平移的圆形色块（从上一个页签滑到当前页签），进入子页时变为圆环、标签交叉淡入替换为子页名；回退／折返仍是两端圆瓣形变，长按回退键弹会话历史列表。
- **会话内页面历史**：回退／折返可跨页签回到刚才的页面并恢复当时状态（主页↔主页不记录，A→B→A 去抖，容量 30）。
- **弹窗改为页内浮层**：弹窗打开时悬浮底栏（含回退／折返键）仍在最上层、可点，不再被系统窗口整层盖住；弹窗从屏幕下方上下平移进出，点入口／上一步／返回键都会先关闭弹窗；返回键、点遮罩关闭，点弹窗卡片本身不穿透；键盘弹出时弹窗自动上移；53 处弹窗外观统一，弹窗套弹窗时由后开者接管。
- **退出与更新**：根页面按返回先提示「再按一次返回键退出应用」（4 秒窗口，可永久关闭）；设置 → 检查更新默认只接受正式版，可勾选接受候选版（需二次确认、仅稳定签名）。
- **草稿保险箱**：含输入的弹窗被误关后重开自动恢复正在填写的内容。
- **竖屏**：应用锁定竖屏；窄屏、大字体、深色与四套主题下底栏与弹窗几何均已复核。

### 稳定性修复

- 修复子页放大／缩小转场掉帧：转场期间整页每帧重组，实测重帧从 17.5% 降到 4.2%。
- 修复离开带子页的页签后约 400ms 内页面点击被静默吞掉（收起中的页签不再拦截输入）。
- 修复横屏下弹窗底部按钮被悬浮底栏盖住：卡片改为避让底栏，标题与按钮固定、正文滚动。
- 修复深链／通知跳转打开子页时动画被误抑制（只有「把子页收回主页」才不补播）。
- 修复冷启动到 Compose 接管之间的返回被直接退出；兜底处理器在首帧后即注销。
- 修复历史列表跳转漏做转场判定、退出确认提示时长与二次返回窗口不一致。
- 重启恢复如实化：真机实测 ColorOS 会推迟开机广播（`DEFER_BY_OPLUS`），提醒要等打开应用时补登记；设置页不再写"重启后自动恢复"，改为如实说明并在被推迟时明确提示。
