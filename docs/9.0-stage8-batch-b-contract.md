# 阶段 8 批次 B：网格定位、人工锚点与修正预览

日期：2026-10-01。范围仅为 8.5–8.7 的纯几何与预览基础设施；不启用 Room，不改变现有课程导入提交路径。

## 已实现

- `VisionAnchorSet`：四个带角点身份的归一化人工锚点，要求坐标有限、四角唯一、凸四边形且来源明确为 `manual`。
- `VisionGridPipeline.perspective`：由四角锚点计算源图到单位正方形的 3×3 单应变换；奇异或非法输入返回空，不猜测变换。
- `correctedBox`：把候选框四角映射到修正空间并生成包围框；任一角无法映射时保留人工检查状态。
- `locate`：根据星期与节次轴定位网格单元；轴重叠、缺失或几何无效时返回空，不能自动确认。
- `preview`：输出候选框修正结果、可唯一定位的 `VisionGridCell` 和告警。结果仍是预览 DTO，不直接写 `Course` 或 Room。

## 边界

当前实现不执行 OCR、图像边缘检测、真实图片透视校准、候选合并或课程落库。人工锚点和候选框坐标由上游视觉服务提供，真实图片、设备 UI、取消流程和双供应商仍需独立验收。重叠轴与无法映射的候选必须留给用户检查；批次 B 不包含发布或合并。
