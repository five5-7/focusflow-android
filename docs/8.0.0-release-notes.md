## FocusFlow 8.0.0 · 第三个正式版

8.0 将 7.2 至 7.12 的连续候选收束为继 6.0 和 7.1.3 之后的第三个正式版里程碑。

### 主要更新

- 今日状态集中管理生活阶段、精力、校园生活、出行方式与电动车电量。
- 收集箱支持待整理、逐步推进和参考流转；任务可安排、恢复、暂停、改期、完成或转成目标。
- 增加固定课表、学校节次表、课程生效期、启停与批量管理，以及地点和通勤估算。
- 空挡页提供课间、课前、课后和无课日自由时段，并用七天纵向时间图展示。
- 历史支持单删、批删和清空，统计由剩余事件重算；任务本身不会随历史删除。
- 统一今日、日程、计划、统计与设置的文字层级、主题颜色、滚动和窄屏布局。

### 稳定性修复

- 重叠课程、连续课程或通勤超过课间时不再生成反向区间，进入计划页不会因此闪退。
- 逾期事项明确显示逾期时长，并提供完成或重新安排入口。
- 通知动作与前台操作使用任务快照校验；任务、历史事件和目标计数一次提交，避免旧页面覆盖新状态。
- 排程按具体日期计算并拆分跨午夜区间；上周同一天、已完成或暂停任务不会错误占用今天或下周。
- 重叠和嵌套课程始终保留最晚结束边界，目标与活动建议统一扣除真实任务占用和缓冲。

### 安装与验证

- 版本：8.0.0，versionCode 513；支持 Android 8.0（API 26）及以上。
- rc.4 基线 Run 306 通过 440 个单元测试、Debug/Release 构建、稳定签名和 APK 元数据校验，并由维护者完成针对性真机验收。
- 正式 APK 从 `main` 的完整门禁产物发布，不重新打包或更换签名，支持覆盖安装。
- 请直接覆盖旧版，不要卸载或清空数据。
- 单次通勤时间覆盖、仅今日交通状态、地图 SDK、云同步和桌面小组件留待后续版本。
