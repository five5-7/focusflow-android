## FocusFlow 7.1.3 · 第二个正式版

按维护者确认，将 7.1.3 作为继 6.0 后的第二个正式版里程碑发布。

### 本阶段主要更新

- 更完整的任务执行与恢复闭环、独立历史事件统计；删除/改期不再抹去已发生的改期记录。
- 任意 5–360 分钟任务时长、收集箱编辑及转为目标/计划的一部分。
- 快速入门章节导航、子页双向转场、四个主入口淡入淡出及底栏子页反馈。
- 真正悬浮底栏、六色主题及旧五色存档兼容；顶部初始避让与滚动显示范围分离。
- 全新自适应应用图标与 Android 13+ 单色主题图标。
- 历史保留与损坏备份失败时的写入保护。
