# 9.0.0-rc.2 UI细节与验收记录

文档版本1.0，2026-10-10；候选9.0.0-rc.2 / versionCode 580。基线rc.1 / 579、Run666、草稿PR #62；未合并、未正式发布。

## 已实现范围

- 新增待办：四个重复选项最多两列、按可用宽度换行，保留“有课日”完整文字；日期选择按宽度换行。只调整控件布局，保存、重复规则与日期语义保持。
- 同类检查：编辑/安排/改期/目标安排/快速记录弹窗中的九组固定选项与冲突操作改为FlowRow，包括优先级、明早/明晚、调整并保存、仍要保存与直接安排；活动弹窗另有八组时长/快捷动作同样改为换行。窄屏或大字号时先换行，不再压缩最后一项。
- 收集箱：“查看全部”启用标题同行操作槽，位于标题右侧；继续只显示最近两条摘要和原有快速记录。
- 底栏：以系统安全区为基准，手机左右和底部使用同一留白。普通手机边距16→8dp，每侧拓宽8dp；历史箭头的实际屏幕位置每侧外移4dp。窄屏/大字号边距8→6dp，每侧拓宽2dp，箭头外移2dp；极窄屏仍为4dp，不新增位移。计算已计入胶囊边缘移动，不叠加超限偏移。大屏仍保留640dp宽度上限与居中布局，安全区不取消。
- 图标：保留聚焦框和流动F轮廓，背景增加方向渐变、柔和投影、抬起的底板与上缘高光；彩色F增加细微明暗层次。Android主题单色图标轮廓、包名与安装签名保持。
