# V2 活动模式真机测试清单

V2 仍在独立分支开发，以下测试不会用于评价活动好坏，只检查转场是否可靠、是否尊重用户选择。

## 快速主流程（约 8 分钟）

1. 在设置中把提前预告设为 5 分钟，连续延长上限设为 2 次。
2. 开始一个 6 分钟的“游戏／娱乐”，下一步填写“喝水”。
3. 确认今日页持续显示剩余时间、预计结束时间和“喝水”。
4. 锁屏或切到其他应用，约 1 分钟后确认收到温和预告。
5. 到点后从通知选择“延长 10 分钟”，确认应用中的延长次数变为 1。
6. 在应用中选择“结束并开始下一步”，确认当前活动结束，并开始“喝水”。

## 时间与恢复

- 用“直到时间”开始活动；若选择已经过去的时间，应自动解释为次日该时间。
- 活动进行中强制关闭应用，再打开，倒计时和下一步应继续存在。
- 活动进行中重启手机，提醒应恢复；如果重启时已经到点，打开应用应进入待确认转场。
- 到点后暂不处理，稍后打开应用，应询问实际结束时间，可选“刚刚”或“按预计时间”。

## 延长与冲突

- 当延长会碰到已安排任务或已确认课程时，应先显示冲突名称和时间，不自动改动原日程。
- 分别记录“还没结束”“不想停”“临时被打断”，确认今日活动卡显示最近原因。
- 达到连续延长上限后，应用和通知都不再提供一键延长；仍可明确结束或重新开始。

## 通知与隐私

- 关闭“活动提醒”后，通知消失，但倒计时、活动记录和手动结束仍可用。
- 重新开启提醒后，正在进行的活动应重新安排预告和到点提醒。
- 关闭精确闹钟权限时仍应收到普通提醒，但系统可能稍有延迟。

## 兼容性

- 从 1.6 覆盖安装 V2 预览版，原任务、课程、目标和旧活动记录不得丢失。
- 旧活动记录缺少 V2 字段时，应自动补默认值，不崩溃。
- 底部导航栏保持正常高度，今日、收集箱、计划、设置页面内容都应可见。
