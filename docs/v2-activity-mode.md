# V2：开始活动与结束转场

## 目标

“开始活动”不只是倒计时器。它需要在娱乐、学习、休息等活动开始前建立一个温和但清楚的结束约定，并在到点后帮助用户真正转向下一步。

## 开始流程

1. 选择活动类型：游戏／娱乐、学习、休息、通勤或自定义。
2. 填写预计时长，也可选择“直到某个时间”。
3. 可选填写结束后的下一步；未填写时由 FocusFlow 根据日程和状态推荐。
4. 开始后，今日页显示当前活动、剩余时间、预计结束时间和下一步。

## 提醒与转场

- 结束前 10 分钟：柔和预告，不要求立即停止。
- 到达结束时间：明确提示“结束活动”，并同时提供“开始下一步”“延长”“现在结束但稍后安排”。
- 选择延长时：提供 10、20、30 分钟选项，并可记录“还没结束／不想停／临时被打断”等原因。
- 延长后再次到点：提示强度略提高，但仍允许用户做明确选择，不使用惩罚性语言。
- 长时间没有回应：不自动判定失败；将活动标记为“待确认”，下次打开应用时询问实际结束时间。

## 与日程联动

- 下一项存在固定开始时间时，预告会显示剩余缓冲时间。
- 延长会造成冲突时，先展示影响，再由用户选择延长、缩短下一项或重新安排。
- 活动结束后，推荐的下一步优先考虑已确认日程、目标频率、精力状态和任务最低版本。
- 活动记录进入统计，但不把娱乐或休息简单视为负面行为。

## V2 数据与状态

- 活动状态：进行中、已完成、已延长、已跳过、待确认。
- 保存计划开始、实际开始、预计结束、实际结束、延长次数和结束选择。
- 设置页允许调整预告时间、最大连续延长次数和是否显示更明确的到点提醒。

## 验收标准

- 应用被切到后台后仍能可靠提醒。
- 重启手机后可以恢复进行中的活动。
- 到点通知可以直接完成、延长或进入下一步。
- 延长导致日程冲突时必须先告知影响，不可静默改动其他安排。
- 所有提醒可关闭；关闭通知不会破坏活动记录和手动结束流程。
