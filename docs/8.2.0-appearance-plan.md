## 一、目标（全部可选）

| # | 特性 | 维护者原话 |
|---|---|---|
| 1 | 页面与卡片渐变 | 「背景渐变，其他界面加卡片渐变」 |
| 2 | 自导入图片背景 + 可调透明度 | 「自导入图片背景」「可调自定义背景的透明度」 |
| 3 | 从图片自动抽取主题色 | 「系统自抽主题色」 |
| 4 | 卡片材质 | 「卡片界面特殊材质」 |

## 二、非目标 / 不变量

- **不动**现有四套内置主题（海盐蓝／薄荷绿／暖杏／暮紫）当前的样子；新主题是**新增**。
- **不动**课程块颜色与 `FocusFlowSchedulePalette`：课表只改**底色**，每门课的颜色仍是数据契约。
- 老装机默认外观不变：所有新偏好键都有默认值，读不到就是"跟现在的样子一样"。
- 不引入网络能力；导入的图片只存在应用私有目录。
- 不为纯外观行为新增开关（沿用仓库规矩：开关只用于后台工作、权限、通知或有意义的用户选择）——外观选项集中在「设置 → 外观」。

## 四、架构

### 1. 共享"表面材质"层（新增 `SurfaceMaterial.kt`）

所有外观的**唯一出口**：输入表面角色 + `AppearanceSpec`，输出画好底色／渐变／图片／纹理 + 遮罩 + 描边的 modifier。

```kotlin
internal enum class SurfaceRole { Page, Card, Dialog, Bar, Timetable }
internal data class AppearanceSpec(
    val pageBackdrop: Backdrop,        // Theme / Gradient(停靠色) / Image(路径, 不透明度)
    val cardMaterial: CardMaterial,    // Tonal / Gradient / Soft / Paper
    val timetableBackdrop: Backdrop,
    val extracted: ExtractedPalette?   // 自抽主题色
) {
    companion object { val DEFAULT = AppearanceSpec(Theme, Tonal, Theme, null) }
}
```

- 页面、卡片、弹窗、底栏、课表**都**走它 → 一处调对比度、一处调参数，避免 30 处各写各的。
- 渐变一律 `Brush`；图片一律 `Image(contentScale = Crop)` + 主题遮罩（`scrim` 角色按当前主题的明暗取 alpha）。
- 纹理只用**程序生成**的 64×64 噪点（不塞图片资源，包体积零增长）。

### 2. 抽取主题色（新增 `PaletteExtractor.kt`，纯函数 + 单测）

`fun extract(pixels: IntArray, maxColors: Int = 4096): ExtractedPalette`

1. 降采样到 64×64（由调用方在后台线程做，纯函数只吃 `IntArray`）；
2. 转 HSV，丢掉过低饱和 / 过亮过暗的像素；
3. 按色相分 12 桶，取"占比 × 饱和度"最高的桶做主色，邻桶做副色、对角色做强调色；
4. 用现有派生规则（`containerOf` / `onOf` / `onContainerOf`）生成完整 scheme，保证文字对比度。

**为什么纯函数**：抽取结果要可复现、可回归（单测喂固定像素数组，断言输出色相区间），不依赖真机。

### 3. 对比度守卫（新增 `AppearanceContrast.kt`，纯函数 + 单测）

- `ratio(fg, bg)`、`needsScrim(background, onBackground, target = 4.5f)`、`suggestScrim(...)`。
- 用在两处：自定义工具里**当场提示**（低于阈值标红），以及导入图片时自动加/加厚遮罩。
- 阈值：正文 ≥ 4.5:1（AA），大字号标题 ≥ 3:1。参考现状：四套主题正文 13.9–14.2:1。

### 4. 渲染接入点

| 位置 | 现状 | 改为 |
|---|---|---|
| 根 `Surface(containerColor = background)` | 纯色 | 页面底色（主题/渐变/图片） |
| `SubpageMotion(containerColor = background)` | 纯色 | 同上（传背景槽位，副页不再各画一层纯色） |
| 卡片容器（`surfaceContainerLow` 等） | 纯色 | `SurfaceMaterial` 的卡片材质 |
| 弹窗卡片（`AppDialog`） | `surfaceContainerHigh` + 柔光阴影 | 同上（保留 8.1.1 的柔光） |
| 课表 / 日程表网格底板 | 纯色 | 课表底色（主题/选色/图片） |
| `FloatingNavigationBar` 底色 | 主题容器色 | 跟随页面明暗（图片背景下自动加厚遮罩） |

### 5. 设置入口（「设置 → 外观」）

在现有主题选择器下新增：更多外观（新增主题）→ 背景（主题/渐变/图片 + 透明度滑杆 + 导入/移除）→ 卡片材质 → 课表底色 → 自定义主题工具（升级版：渐变停靠色、导入、抽取、预览、对比度提示、恢复默认）。

## 五、分阶段与验收

| 阶段 | 内容 | 验收证据 |
|---|---|---|
| A. 地基 | `AppearanceSpec` + 偏好读写 + `SurfaceMaterial` + 对比度守卫 | 单测（默认值/迁移/对比度算法）+ 真机截图：默认外观与 8.1.1 **逐像素一致** |
| B. 渐变 | 页面渐变 + 卡片渐变 + 每套主题的停靠色 | 真机截图 + 5 套主题对比度复测 |
| C. 图片背景 + 抽取 | 导入、降采样、透明度、遮罩、抽取主题色 | 真机截图（浅/深 2×3 场景）+ 抽取单测 + 内存/首帧数据 |
| D. 课表底色 | 选色 / 导图（只动底色） | 真机截图 + 课程块颜色未变的断言 |
| E. 材质 + 新主题 + 工具 | 柔光/纸感（毛玻璃先测帧时间）、3 套新主题、自定义工具升级 | 帧时间 (`gfxinfo`) + 截图 + 说明书更新 |
| F. 收口 | 说明书/快速上手/路线图/CHANGELOG + 版本与发布 | 单测全绿 + 真机验收记录 |

**风险与对策**

- 图片内存：一律降采样到屏幕尺寸以内再解码（`inSampleSize`），后台线程 + 缓存，绝不整图解码。
- 掉帧：`Modifier.blur` 只在 API 31+ 存在，且要每帧抓背景层；**先做帧时间实测**再决定是否收毛玻璃。
- 对比度：任何背景都要过 `AppearanceContrast`；四套主题 × 浅/深 × 有图/无图全部复测。
- 包体积：纹理程序生成，无新图片资源。

## 六、阶段实测记录（真机 OPPO ColorOS 16 / Android 15，1440×3168）

### 阶段 A：默认外观不变（验收线）

同一页面（计划页）、同一路径，装 8.1.1 发布包与含渐变能力的新包各截一张：

```
region=full samples=1140480 meanAbsDiff=0 changed(>12)>0%
```

**逐像素完全一致**：默认外观下背景层不新增任何绘制节点，这条是结构上成立的，不靠调参。

### 阶段 B：页面渐变（设置 → 外观 → 页面背景 → 主题渐变）

页面左边缘一列（x=40）取样，自上而下：

| y | 主题渐变 | 跟随主题（默认） |
|---|---|---|
| 300 | rgb(231,223,220) | rgb(236,233,231) |
| 1100 | rgb(235,223,218) | rgb(242,236,232) |
| 1900 | rgb(238,229,224) | rgb(242,236,232) |
| 2700 | rgb(240,233,229) | rgb(242,236,232) |

上到下平滑过渡（9 个通道级差），默认则是一条恒定色。整图差异 12.2% 像素（只有背景区域变了，卡片未动）。

对比度（暖杏浅色，WCAG）：

| 前景 | 渐变顶 | 渐变底 | 卡片 |
|---|---|---|---|
| 正文 onBackground | 12.63 | 14.04 | 16.13 |
| 说明性小字 onSurfaceVariant | **2.86** | 3.18 | — |

**已知问题（既有，不是渐变引入）**：说明性小字在纯色页面下也只有 **3.21**，本来就低于 WCAG AA 正文阈值 4.5；
渐变把它压到 2.86（−0.35）。视觉盲评独立指出了同一处（"说明性小字对比度稍弱"），与实测一致。
处理方向：在"统一设计语言"里把 `onSurfaceVariant` 从 `lerp(text, White, 0.45)` 收深一档，
让副文本在任何背景下都过 AA；渐变本身不再加浓（当前顶部 14% 已是"肉眼可见"与"不压对比度"的折中）。

阶段 B 的视觉盲评结论：「存在从上到下的渐变」「卡片依然清晰、有分层感，没有糊在一起」「整体是加分的」。

## 七、追加范围（维护者后续补充，按时间顺序）

### 7.1 渐变强度可调（已实现）

「设置 → 外观 → 页面背景 → 主题渐变」下增加强度滑杆 0–200%，默认 100% = 设计值（0% 等于纯色）。
默认值写进偏好键并带默认值，老装机读不到就还是设计值。真机实测：100% 时上下两端级差 22、
196% 时 34；最强档正文对比度仍 ≥7:1（单测锁住）。

### 7.2 悬浮栏描边与箭头（已实现）

维护者口径：不要 2dp 硬灰线，改成"靠里浅、靠边深"的过渡。做法是把描边收成 0.6dp 发丝线（12% 透明度），
靠阴影（3dp → 7dp）把边缘柔化出去。箭头从 28dp 触控框 / 20dp 图标改为 38dp / 28dp，并向下内收
（真机实测：80×80px → 112×112px，上沿下移 56px、中心下移 24dp）。

### 7.3 课表/日程表底色（已实现）

「设置 → 外观 → 课表与日程表底色」：跟随主题／选颜色（8 个浅色预设）／图片（可导入 + 不透明度）。
**只动底板**，课程块与日程块的颜色来自各自数据、一行没碰。真机验证：日程页时间轴底板采样为
选中的"暖纸" rgb(242,236,232)，与页面底色 rgb(240,241,241) 可区分。

### 7.4 卡片材质（已实现，19 处卡片已收编）

新增统一卡片组件 `FocusCard`：默认（原样）／渐变／柔光／纸感。纸感噪点是**程序生成**的 64×64 贴图
（不增加包体积），用线性同余保证可复现，单测断言"两次调用完全一致""不会把卡片压暗"。
全应用共 48 处卡片、其中 19 处单行写法已机械收编；剩余（多行写法、`ElevatedCard`/`OutlinedCard`、
带 `onClick` 的卡片）待继续收编。

### 7.5 底层分离效果 + 固定背景色（**待实现**，维护者原话）

> 「我期望你提供一个底层分离效果，以适配自定义的图像以及实现固定背景色，现在的方案也保留」

拆成两件事；**现有三种背景（跟随主题／主题渐变／图片）全部保留**，以下为新增可选模式：

1. **固定背景色**：页面背景增加"选颜色"档（目前只有课表/日程表底板能选色）。
   实现要点：新增偏好键 `appearance_page_color`（默认 0 = 未选）；`appearanceBackdrop` 的 Page 角色
   目前只认 Timetable 的选色，要一并支持。
2. **底层分离效果**（偏好键 `appearance_layer_separation`，默认关 = 现状）：
   - **背景层固定**：底色/渐变/图片只画一次，不随内容滚动、不随页面转场缩放平移
     （现状：副页层各画一遍背景，转场时图片会跟着缩放；课表/日程表底板在滚动内容里，会跟着滚）。
   - **内容层分离**：内容放在一块**不透明**的内容面上（主题 surface 色 + 可选圆角 + 四周留边），
     背景在留边处露出来。既做到"背景固定"，又不会退回 8.1.1 修过的"两层互相透出来"——
     **内容层必须不透明**是硬约束。
   - 与自定义图片配合：图片全屏铺满且固定，内容面浮在上面，正文对比度由内容面自己保证
     （图片上的遮罩只作用于露出来的边缘区域）。

验收线：默认（分离关）逐像素与 8.1.1 一致；三种旧背景模式行为不变；开启分离后，
滚动与页面转场期间背景像素在屏幕上**坐标不动**（用前后帧采样对比证明）。

> **更正**（维护者随后澄清）：要的不是这种"留边露出背景"，而是**渐变的作用长度**——
> 固定时渐变只跨一屏，跟随内容时跨整段内容，于是每屏的颜色变化更缓。
> 上面这套"底层分离"实现已**全部删除**（开关、留边绘制与对应单测），改为下面的 §7.6。

### 7.6 渐变：自选配色 / 跟随内容 / 深色适配（部分完成，**等真机再调**）

维护者后续口径：「渐变色是不是可以自选色」→ 已做；「背景可以是滚动的，也可以是固定的，
如果是滚动的，那么渐变色的上下界会比固定的长很多」→ 已按"整条渐变铺 3.2 屏、当前一屏只截
1/3.2 段"实现（纯函数 `windowStops` 有单测）；「注意适配深色模式」→ 已做。

已完成：
- **自选渐变配色**：8 组"顶色→底色"色板 + "跟随主题"档；真机实测选"雾蓝→浅蓝"后页面端色即为该组。
- **渐变跟随内容**：见上；**真机效果未确认**（开关状态靠 dump 读取不稳、`nestedScroll` 挂载点改过一次，
  两次滚动前后取样一致，无法判定是开关没开还是机制没生效）。
- **深色模式适配**：深色下渐变改为一套独立幅度（顶 +10% 白、底 −25% 黑；浅色是 +85% / −7%），
  自选浅色与固定背景色在深色下按 22% 权重压到深色底上（保留色相、整页仍是深色）。
  单测断言：深色下渐变各点亮度 < 0.35、正文对比度 ≥ 7:1；浅色模式仍原样使用用户选色。
- **对比度体检**（第 7 项）：自定义主题编辑器当场显示六对关键前景/背景的对比度，不达标标红。
  过程中发现"暮紫的强调色 3.27:1"——强调色用于图标与强调块（非正文），按 AA Large 的 3:1 口径达标；
  原有四套配色是维护者要求冻结的，所以调的是**判定口径**而不是颜色。

**等真机时要做**（维护者要求「稍后准备调整渐变，等到能真机的时候」；真机测试每天 17:00 起暂停）：
1. 确认"渐变跟随内容"是否真的生效（若 `nestedScroll` 仍不生效，改用页面自身的 `ScrollState`——
   `SettingsScreen` 本来就接收外部 ScrollState，可以直接取滚动量）。
2. 对着真机调渐变的默认幅度与方向（浅色 / 深色各一遍）。
3. 卡片材质（渐变 / 柔光 / 纸感）的真机观感确认；默认材质"逐像素不变"目前只验了计划页
   （今日页的差异经查是内容随时间变化，不是样式）。
4. 箭头位置（当前 TopStart / TopEnd 偏移 −2dp / 0dp）在真机上确认是否还要更靠角落。

### 7.7 自定义主题工具升级（第 7 项，已实现，待真机走查）

维护者原话「自定义工具要升级」，拆成五件事，逐条落地：

| 要求 | 做法 |
|---|---|
| **渐变停靠色** | 抽出 `GradientStopsControls`（八组「顶色→底色」+ 跟随主题 + 强度 0–200% + 跟随内容开关），「设置 → 外观」与自定义主题工具**共用同一份实现** |
| **背景导入 / 透明度** | 抽出 `PageBackdropControls`（四档背景 + 导入/移除 + 不透明度 + 从图片抽色），同样两处共用 |
| **抽取** | 工具里复用同一个 `PageBackdropControls`；差别只在抽色结果落到**工作副本**（`onColorsChange`），确认为「应用此配色」后才换全局主题 |
| **预览** | 新增 `AppearancePreview`：把候选配色做成真正的 `FocusFlowThemeSpec`，再用 `Modifier.appearanceBackdrop` + `FocusCard` 画一个迷你页面 —— **预览与应用后是同一段渲染代码**，不会各自漂移 |
| **对比度提示** | 已有 `ThemeContrastAudit`（六对逐项，不达标标红），本次未改 |

顺带做掉的两件事：

- **预设升级成"整套外观"**：`ThemePreset` 增加可选 `appearance`，`ThemePresetCodec`（纯函数 + 7 条单测）
  负责编解码。**老预设（只有 `name` + `colors`）读出来 `appearance == null`**，含义是"只管配色"，
  应用它不动当前的背景与卡片 —— 升级前后行为逐字一致；写回时也不会凭空多出 `appearance` 键。
  保存时用勾选框决定"只存配色"还是"连外观一起存"（默认勾选）。
  预设里记的图片若已被删除，`AppearanceSpec.withExistingImages` 会把这一档降级为跟随主题
  （与「移除图片」同口径），而不是套一个画不出来的模式。
