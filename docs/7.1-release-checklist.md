# 7.1.0 稳定正式版验收

目标：6.0 之后第二个稳定正式版。仅自动构建通过不构成稳定版验收；分发的 APK 在真机验收前称为候选包。

## 自动门槛

- 同一提交 `:app:testDebugUnitTest` 与 `:app:assembleDebug` 均成功。
- 保留测试 XML、APK 构建编号、SHA-256；稳定签名准备成功，证书与既有稳定包一致。
- 回归覆盖 1500 次追加后原计划／完成／改期统计不变、500 条原始记录中的早期记录可删除、备份路径故障不崩溃且禁止 apply/commit/remove/clear。
- 不更改包名或既有存储键；不清空旧用户数据；不能恢复已被旧版本截掉的记录。

## OPPO / ColorOS 真机门槛（必须由实际设备验证）

1. 不卸载旧版本，覆盖安装；核对任务、课表、目标、习惯、主题、历史与权限仍在。记录原版本和新构建号。
2. 新建 10 分钟任务，检查保存、重启后时长和时间轴；完成、改期、放回收集箱、删除后核对当日与本周统计。
3. 原始事件超过 50 条时滚动到最早记录；删除指定一条后关闭重开，确认仅少一条，总数一致。
4. 今日→收集箱、计划→各子页、设置→高级工具→通勤→校园地点、外观→自定义主题，进入／返回均有方向一致的转场且逐级返回。
5. 长列表滚动后往返保留位置；快速连点、动画中系统返回、切底栏不出现错页、残影、空白或误执行删除。
6. 快速入门五章节全部可点选；上一节／下一节／关闭均正常；窄屏、大字体、横屏、深色模式与系统关闭动画下不遮挡。
7. 通知允许后：桌面等待一分钟测试、日程提前与到点提醒；改期清除旧提醒；完成／删除后不再响；重启与升级后恢复未来提醒。
8. 后台活动与自启动按设备设置允许；记录实际延迟，不把进入应用后的补发当成功。饭点忽略当天不重弹，跨天继续正常。
9. 游戏／视频无使用情况访问权限时仍提醒收尾；授权后检测路径与普通活动分别测试。
10. 连续实际使用至少一个完整昼夜，查看本地崩溃日志；任何数据丢失、错误统计、闪退、后台漏提醒均阻断正式发布。

## 已知边界

- 历史仍使用本地 JSON 全量读写；已取消数量截断，但尚未迁移数据库，超大历史需要性能实测。
- 损坏备份属于人工恢复材料，不是自动恢复／云备份；失败保护提示出现期间的操作不会保存，成功重试后请重新打开应用。
- 构建候选不合并 main、不自动宣布稳定；真机通过后将验收过的同一 APK 正式分发。
