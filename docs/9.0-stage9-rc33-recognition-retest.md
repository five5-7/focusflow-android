# rc.33：真实课表识别定向复测

当前候选：8.3.0-rc.33 / versionCode 567。rc.32 曾因错误基线回退识别入口，现已恢复分阶段解析接线。目标设备为同一台 OPPO / ColorOS 17 / Android 17 测试机。rc.32 的真实课表失败摘要为 `bytes=4485 sha256=9ca64a70a96e syntax=false invalid-json`。

## 安装

1. 只安装 rc.33 构建 对应的稳定签名 APK，不能复用旧候选。
2. 执行 `adb install -r <APK>`，确认 `Success`；核对 `versionName=8.3.0-rc.31`、`versionCode=565`。
3. 保留现有 key、Qwen/Qwen3-VL-8B-Instruct 默认服务和校园生活开关；不要清除数据。
4. 记录计划 → 课程的已确认/待确认计数，并先收起输入法。

## 识别

1. 计划 → 课程 → 截图识别，选择同一张真实课表。
2. 等待一次完整请求，不重复点击；记录是否进入审核页。
3. 审核页出现时，检查候选名称、星期、开始/结束节次、坐标警告；未确定的候选逐条人工处理。
4. 仍失败时，完整复制括号内从 `bytes=` 到末尾的诊断，包括 `syntax=`、shape 和 `stage=`；不要复制模型原文、key 或真实课表图片。
5. 课程计数前后必须一致；失败不得产生自动导入。

## 结果判断

- 出现审核页：说明响应已通过格式清理、归一化和安全解析，继续执行确认/编辑/拒绝。
- 显示“没有识别到课程”：说明格式已解析，但模型未产出可审核候选；这与 JSON 失败不同。
- 仍显示 `invalid-json`：说明模型仍返回未支持的 JSON 变体；回传完整 `stage=` 后再决定是否增加兼容。
- 有审核页但候选位置为空：属于人工审核路径，不得强行确认；记录警告并回传。
