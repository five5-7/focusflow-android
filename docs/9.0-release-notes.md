# FocusFlow 9.0 · 第六个正式版

**9.0.0 / versionCode 581**，沿用原包名与稳定签名，可覆盖安装既有正式版或 9.0 候选版。

## 日常使用

- 收集箱记录可整理为待办或计划；重复安排、完成历史、活动记录与回收站恢复组成日常流程。
- 课程按独立课次管理，连续课程展示、教务学期选择与课程提醒更易维护；日程保留日、周、固定课表视图。
- 优化“有课日”等选项的换行、收集箱标题与“查看全部”的同行布局，以及标题右侧帮助、时间轴图例和卡片触摸反馈。
- 底部导航加宽、左右与底部留白一致。前后箭头在 rc.2 的手机布局上各再外移 2dp，极窄窗口和受限宽度保留限幅。
- 启用维护者选定的 B1 流动丝带图标：半透明丝带、靠中间的 F 竖笔，以及缩短的金色曲横；同时保留主题单色图标。

## 稳定性与实用性

- 更新页分别显示已安装版本和可用版本，支持候选序号比较，避免把旧正式版当成当前版本或提供降级。
- 下载使用临时文件；连接中断、HTTP 错误和非 APK 内容不成为可安装结果，保留原有完整文件。
- 今天与明天都没有空档时进入手动改期，避免生成可能冲突的默认安排。
- 可选快速记录服务在权限或系统限制下保留开关意图，返回前台后恢复；关闭后不再因重建续启。
- 启动快照读取异常时保留记录并显示诊断，崩溃日志按字节限量；活动日/周范围使用本地日历边界。

通知项按维护者决定接受；此前两次后台延迟观察保留，未证明权限是原因，也未宣称本轮修复。完整一天使用、无空档改期的受阻真机场景、下载中断重试及部分外观场景仍缺完整设备证据。本次按维护者明确发布指令发布，不将这些项目写成通过。详情见 [发布记录](https://github.com/five5-7/focusflow-android/blob/main/docs/9.0-publication-20261011.md)。
