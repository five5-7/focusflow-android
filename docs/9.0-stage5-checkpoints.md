# 9.0 阶段 5 第一轮：六个检查点

候选：8.3.0-rc.24 / versionCode 558。阶段 4 OPPO 真机合并验收仍待完成；本轮六个检查点不等于阶段 5 全部完成。Room 产品激活保持关闭。

1. **活动入口**：今日页移除「现在做什么」、下一件推荐及全局自由开始。进行中的会话仍提供控制入口；旧版独立活动历史保持可读。
2. **待办可选计时**：待办详情「更多」提供开始计时；新会话使用稳定待办 ID。旧会话缺少关联 ID 时保留独立历史，不按同名推断归属。
3. **单活动保护**：开始前重新读取当前会话，已有进行中的会话直接进入控制；仓库写入再验证无第二段开放会话，CAS 写入避免并发覆盖。
4. **待办计时历史与统计收纳**：同一待办的已结束会话累计段数和分钟数；今日页去掉空生产力统计卡及活动记录卡，本周回顾不再占计划主入口。原始记录未删除。
5. **重复规则状态**：暂停与继续沿用现有路径；新增停止与恢复性删除，停止后不再产生实例，待处理实例归档，旧实例和事件保留，最近删除可找回规则。
6. **今日与明天首屏**：今日页课程和已安排待办在前，需要处理仅显示紧凑总数并位于收集箱之前；明天预览最多两项，点击可查看完整明日安排；权限缺失才插入提示。

本轮验证范围：旧 Room v4 会话迁移到 v5 时 task_id 为 null；已有活动历史继续可读取；同名但不同待办的计时不串联；第二个并行计时被拒绝；停止与删除重复规则后不生成新实例。CI、签名包和 OPPO 验收结果另记实施计划。

后续阶段 5：暂停／继续、仅结束／完成待办／改期后结束的完整生命周期；规则条件「复习今天课程」；今日批量改期及整批撤回；错过安排的提醒和时间占用规则；完整明日操作页。上述均未在本轮宣称完成。
