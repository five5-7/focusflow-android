## 本轮 UI 与动效优化（冻结前）

- 底栏回退/折返箭头在 260ms 顶角收缩完成前保留组合，避免图标瞬隐与形变不同步；关闭动画时仍立即移除。
- 弹窗关闭或收起时主动隐藏输入法，再清除焦点，避免 IME 的 adjustResize 状态把底栏和窗口压缩到屏幕中部。
- 弹窗卡片改为填满可用宽度、最多 560dp，保留外侧 24dp 留白，窄屏和大字体下不再被 280dp 最小宽度挤压。
- 快速记录输入时不再给根布局施加 IME 内边距；输入法只调整页面与弹窗区域，悬浮导航栏保持在屏幕底部。
- 宿主只预留悬浮栏未被键盘覆盖的高度，避免弹窗上方再出现重复空白。
- 未改动导航方向、动画时长、数据契约或课表识别；本轮完成后冻结候选。

## 退出本轮范围

部分能力服务探针、识别超时/配置变更/HTTP 错误分类、确认/编辑/拒绝与真实课表准确率均随新识别方案暂缓。旧版本保留原有实现，不声称这些未执行项已通过。

旧系统矩阵和第二台设备兼容性属于后续扩展。当前测试设备系统升级不构成本轮矩阵不符。
