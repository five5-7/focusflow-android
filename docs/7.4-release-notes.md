## FocusFlow 7.4.0

FocusFlow 7.4 聚焦低成本的精力基线采样。它不会把一天固定在单一询问时刻，而是在上午、下午和晚上轮换收集少量主观记录；数据足够稳定后自动降低频率，只在每周少量日期抽查。

### 本次更新

- 默认每天最多一次，按时段轮换，避免只得到单一时间的结论。
- 单时段六条样本且结果较稳定后暂停日常追问；持续波动时最多十二条，避免无限询问。
- 三个时段完成后进入维护期，仅周一、周三、周六抽查。
- 可选“加速建模”默认关闭；开启后只有第一次签到完成且当天仍有至少四小时的未过期时段，才安排第二次。
- 保留固定时间模式，饭点提醒、前台应用检测和外部睡眠接入均不随本版本重新开启。

### 使用说明

精力记录只反映你当下的主观感受，用于本机提示；样本不足时应用不显示结论，也不会自动调整课程、日程或任务。所有记录保存在本机。

### 安装

- 包名：`com.sakata.focusflow`
- 最低 Android：8.0（API 26）
- 请直接覆盖已有 FocusFlow，不要卸载，以保留任务、提醒和精力记录。

发布时填写最终 APK 文件名、大小、SHA-256 与对应 Actions run 编号；这些值必须来自成功的正式版构建。
