## 二、逐档验证（每档一张截图 + 采色）

- [ ] 页面背景 · 跟随主题：`rgb(242,236,232)`（暖杏浅色）
- [ ] 页面背景 · 主题渐变：顶端→底端级差 ≈22（强度 100%）、≈34（196%）
- [ ] 页面背景 · 固定颜色：选中色板即页面主色（已验 `#F6F1EC`）
- [ ] 页面背景 · 图片：只存本机；不透明度 12% / 97% 两张（已验 97% 偏冷蓝）
- [ ] 从图片抽取主题色：强调色随图片主色变化（已验变蓝）；画面太素时提示且**不改主题**
- [ ] 渐变配色：八组各一张，端色 = 所选「顶色→底色」
- [ ] **渐变跟随内容**：先截开关下面那行「当前：跟随内容（…）／固定一屏（…）」确认状态，
      再在长列表上滚动前后各截一张、在 `x=20` 固定屏幕坐标取样——跟随模式两次取样应不同，
      且单屏内级差远小于固定模式
- [ ] 卡片材质：默认（逐像素）/ 渐变 / 柔光 / 纸感 各一张
- [ ] 课表与日程表底色：跟随主题 / 选颜色 / 图片 三档各一张

- [ ] **自定义主题工具**（第 7 项）：预览块排版正常；改渐变/材质时预览当场变化；
      「从图片抽取主题色」只改工作副本（点「应用此配色」后才换全局）；
      保存预设勾选/不勾选外观两种各存一套，点「应用」的表现符合预期；
      **老预设（升级前存的）应用后背景与卡片不被改动**；删除被预设引用的图片后再应用该预设 → 降级为跟随主题不崩；
