# FocusFlow 9.0 最终收尾验收说明（2026-10-07）

## 结论

本轮没有把 9.0 宣称为完成或发布。当前候选为 **8.3.0-rc.34 / versionCode 568**，基于 rc.33 冻结候选追加快速记录键盘布局修复。

已确认的工程和真机成果继续保留：P0 同步/签名/启动/四页导航、通知与真实重启恢复、外观和动画矩阵、覆盖安装数据保留、压缩连续使用稳定性，以及课程身份代码的存储路径。Run 554 的同机记录为这些结果提供了真机证据；当前设备 OPPO / ColorOS 17 / Android 17 就是本轮维护目标。

同一设备人工复测真实课表仍未进入审核页，诊断为 invalid-json。因此新的课表识别链路、审核确认/编辑/拒绝、部分能力服务探针和相关错误分类暂缓，不再继续放宽门禁或迭代解析器。旧版本保留原有识别入口与实现；门禁前代码另冻结在 legacy/pre-vision-gate-20260914，仅作历史对照，不覆盖当前产品分支。

## 本轮已完成

- 将过时的阶段 9 计划、旧候选复测和旧设备矩阵移入 legacy/，归档文件不再修改。
- 补充 CourseParentIdPersistenceTest：两个课次共享父 courseId 写入后，由新的 PrototypeStore 实例读取，直接断言课次 ID 和父 ID 均保持。
- 更新活动状态、README、版本规则、变更记录和云端/本地连续性审计；rc.34 沿用 Run 573 的 rc.33 基线和已升级目标设备。
- 保留可复核的 rc.33 稳定签名产物：Run 573 构建通过，APK 可从 [Run 573 artifact](https://github.com/five5-7/focusflow-android/actions/runs/37611046520/artifacts/11477363939) 下载。
- rc.34 键盘布局修复由 [Run 583](https://github.com/five5-7/focusflow-android/actions/runs/37727371104) 验证通过；稳定签名 APK artifact 可下载，sha256 为 `a16f3d2ab051bf5734fb5c22afe44ee4872c572caecdc0d956ed0c82a0495ec8`。
- 课程父 ID 回归测试由 [Run 577](https://github.com/five5-7/focusflow-android/actions/runs/37646081043) 验证；最终文档与材料打包由 [Run 578](https://github.com/five5-7/focusflow-android/actions/runs/37647923908) 验证。两次提交均不改变 APK 功能。

## 冻结前 UI 与动效优化

- 修复底栏箭头瞬时消失而顶角仍继续收缩的问题。
- 弹窗关闭时主动收起输入法；窄屏弹窗按可用宽度布局，保留 24dp 外边距。
- 快速记录输入时导航栏不再被输入法整体顶起，IME 避让限定在页面与弹窗区域；宿主只预留未被键盘覆盖的底栏高度。
- 动画常数、导航规则、课表识别和 legacy 内容均未改动。

## 仍未完成

1. 在真机上手动确认已经“归为同一门课”的课次，退出应用再进入后仍显示为同一门课。自动测试只覆盖存储层，不替代 UI 复核。
2. 完整一天连续使用；现有证据是约 25 分钟、76 次四页切换的压缩 soak。
3. Keystore 换机、失效和备份排除的实际设备证据。
4. 最终版本范围、更新说明、合并、tag 和 GitHub Release。当前没有发布授权，因此仍是候选。
5. 旧系统 ColorOS 16 / Android 15、第二台设备兼容性属于后续扩展，不是当前升级设备的阻塞项。

## 当前人工验收边界

安装 rc.34 的稳定签名 APK，不清除数据，先确认版本为 rc.34/568。Run 573 的 rc.33 APK 仍作为基线对照。课程归组复核前收起输入法，记录进入计划页前后的课程数量和显示分组。若已明确归组的课程重启后仍拆开，再作为具体 UI 缺陷继续定位；仅同名但未确认的截图导入课次分开属于当前设计。

识别失败不得产生自动导入。除非重新立项，不再要求为 9.0 构造本地代理、放宽 HTTPS/结构化门禁或增加 ADB 自动化。
