# FocusFlow 7.11 课程、空挡与通勤完善

状态：`7.11.0-rc.1` 已实现，等待自动构建与真机验收。历史记录删除不属于本版本，保留为 7.12 数据治理任务。

## 本版范围

- 课程：启用／停用、可选生效起止日期、单门删除、批量删除；旧课程默认继续生效。
- 空挡：建议、课间、自由时段、课表四类顶部切换，保留原建议和排入能力。
- 通勤：路线实测校准优先；四档距离可调；未知路线默认时间可单独关闭。
- 数据边界：删除课程不删除地点、节次、任务和历史；停用课程不删除任何资料。

## 估算优先级

1. 用户路线实测校准。
2. 可判断的近／较近／较远／远档位。
3. 已开启的未知路线默认时间。
4. 未开启兜底时不自动预留。

档位与默认时间都是规划缓冲，不是地图导航结果，也不读取实时定位或自动推断车辆电量。

## 验收

- [ ] 旧课程升级后仍可见、默认启用且无日期限制。
- [ ] 日期边界当天包含在生效期内，停用课程不参与课表和空挡。
- [ ] 单删与批删均有影响说明，取消不改数据。
- [ ] 四类空挡在空数据、窄屏和大字体下仍可操作。
- [ ] 通勤档位保持由近到远非递减，关闭未知路线兜底后不生成虚假时长。
- [ ] 浅色、深色、自定义主题和 OPPO / ColorOS 真机验收。
