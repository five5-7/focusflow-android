# FocusFlow

当前发布版本：**8.0.0**（versionCode 513）。当前候选：**8.1.0-rc.6**（versionCode 519），含统一动效规范、副页深度缩放转场、底栏形变与选中色块、退出确认与页面历史、检查更新。候选只用于构建与真机验收，不等于已发布。

本地优先的 Android 日程与执行辅助应用（`com.sakata.focusflow`）。核心目标不是维护一张完整日历，而是**降低记录压力、按当前状态调整提醒、在错过计划后帮助恢复**。

最新正式版为 [8.0.0](https://github.com/five5-7/focusflow-android/releases/tag/v8.0.0)。候选版只用于构建和真机验收，不等于已发布；版本规则见 [VERSIONING.md](VERSIONING.md)，更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 功能概览

**四个入口**
- 今日：现在、接下来与收集箱固定在前；收集箱分为待整理、逐步推进和参考，推进条目的下一步可派生为关联任务；同时显示计划完成率、今日改期和完成记录
- 日程：日／周时间轴，任务与活动可直接开始、改期、完成或删除
- 计划：堆叠入口进入课程、空挡建议、目标与执行、本周回顾、历史记录、资料工具箱与暂停项目
- 设置：高频提醒、外观和作息留在首页；地点、AI、识别、应用检测与稳定性统一进入高级工具

**课表与空挡**
- 课表截图识别（可选硅基流动视觉模型 Qwen3-VL）+ 手动录入，楼级自动归并、冲突提示
- 空挡 / 自由时段扣除课程与已有安排；「空挡适合做什么」给出内容建议并一键排入（结合精力规律、地点提示、历史完成率排序）

**目标与执行**
- 目标 = 预期结果 + 第一步行动 + 完成标准 + 每周次数 + 单次时长 + 最低版本；按空挡自动排本周目标
- 完成率学习：自动排优先历史完成率高的时段
- 每个目标独立关联真实资料；常用标记不自动套用。AI 搜索只生成候选行动，确认真实资料后才保存
- 本周回顾汇总计划完成率、改期与待恢复数量；统计基于发生过的事件，删除或改期不会改写历史记录；样本足够时提示常见改期时段，所有判断只在本机完成

**活动与自律**
- 活动模式：开始前约定结束时间与下一步，到点转场、限次延长
- 安排空闲活动（游戏/视频/学习/休息/运动/自定义）：按真实类别提醒开始与收尾，通知送达不会自动写入“正在娱乐”；仅游戏/视频在已授权时检测前台应用

**生活与习惯**
- 习惯基线：生活阶段（假期/上学/考试周）+ 多方案 + 按星期分组作息
- 饭点学习、睡前减速、精力记录（状态询问）；饭点忽略后当天不重弹，次日自动续排
- 提醒打扰控制：免打扰时段 + 一次性静音

**外观与稳定性**
- 主入口之间左右平移（普通 80dp、跳转 96dp），底栏固定；子页从底栏对应图标放大展开、返回时缩回同一图标并同步淡出（深度缩放），底栏所属入口在子页时显示圆环并替换为子页名。
- 根页面返回需二次确认（提示 4 秒内再次返回才退出），可点「不再提示」永久关闭，设置 → 退出确认 可改回；非今日页先回今日主页。回退／折返键为底栏两端圆瓣形变，有历史时伸出、无历史时收回，长按回退键弹会话历史列表；弹窗草稿关闭后重开自动恢复。
- 设置 → 检查更新：默认只接受你 GitHub 仓库的正式版（tag vX.Y.Z），可勾选「接受候选版」（需二次确认、仅稳定签名）；应用内下载后调系统安装，可开自动检查。
- 新的“聚焦框＋流动 F”矢量应用图标，自适应桌面裁切，Android 13+ 支持单色主题图标。顶部安全留白随正文滚动，初始标题不被状态栏遮住；滚动时可延伸到状态栏后并柔和渐隐，不再被下沿固定裁断。
- 底栏叠放在页面上，内容可滚到栏后，只有列表末尾预留实测底栏高度；选中态为图标后**会平移的圆形色块**（从上一个页签滑到当前页签，约 260ms，随动画速度换算），进入子页时改为圆环。系统安全区、窄屏、大字体及键盘避让保留。
- 四套内置六色主题 + 自定义六色预设 + 深色模式；新增独立导航栏色、自动对比文字；卡片从中性色派生。兼容旧五色存档及已有颜色编码。
- 设置 → 外观 新增「动画速度」四档（关闭／较快／标准／较慢），统一作用于页面转场、底栏形变与选中色块；系统「移除动画」设置仍然生效。
- 弹窗改为页内浮层：打开弹窗时悬浮底栏（含回退／折返键）仍在最上层、可点，不再被系统窗口整层盖住；底栏会与遮罩同步压暗，避免"页面暗、底栏亮"；返回键与点弹窗外面都能关闭，点弹窗卡片本身不会穿透关闭；键盘弹出时弹窗整体上移到键盘与底栏之上。全部 53 处弹窗统一外观（28dp 圆角、24dp 内边距、同 Material3 字体与按钮排布）。
- 应用锁定竖屏（横屏几何作为大屏/分屏兜底保留）；子页放大／缩小转场不再每帧重组整页，release 包实测重帧从 17.5% 降到 4.2%。
- 本地崩溃记录（设置 → 稳定性与崩溃：查看／复制／清空，不上传）
- 纯 Kotlin 单元测试覆盖数据兼容、时间轴、规划、提醒策略、条件显示、目标执行依据、导航历史与转场规则（84 个测试类 / 484 条用例）

## 构建

目标设备需 **Android 8.0（API 26）** 或更高。

```bash
# 用 Android Studio 打开本目录；或命令行构建（仓库未附带 Gradle wrapper，需本机安装 Gradle 8.7）
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

运行单元测试（CI 同时验证 debug 和 release；分发 release APK）：

```bash
gradle :app:testDebugUnitTest :app:testReleaseUnitTest
```

## 发布

7.1.3 专用发布工作流仅在该工作流合入 main 或手动运行时执行：检查 run-158 来源、应用源码、APK 哈希、版本及签名后，先上传草稿附件、验证远端校验值，再公开为 Latest。同名 tag/Release/附件不一致时停止，不覆盖、不删文件、不重新构建。需要 Actions 的 contents:write 和 actions:read；不读取签名私钥。应用内路线图沿用 run-158 的候选文案，以保留已验证 APK 不变。

GitHub Actions 在 main 的 push、面向 main 的 pull request 或手动运行时执行单元测试并构建稳定签名 APK（artifact）；普通功能分支 push 不会单独触发。APK 和 artifact 名称包含 Actions run 编号。通过自动测试只能分发候选包，真机验收后才把同一产物发布为稳定正式版。

7.1 起任务历史不再按 1000 条截断，界面仍只展示最近事件；已有 JSON 字段与存储键不变。旧版本已截掉的记录无法恢复。原始习惯事件独立保留最多 500 条，可浏览全部保留记录并逐条删除。损坏数据备份失败时暂停所有本地设置写入并显示提示，释放空间后可重试。

### CI 覆盖安装签名

为保证 Actions 产物能覆盖安装已有 FocusFlow，仓库使用下列四个 GitHub Actions Secrets（不要提交到仓库）：

- `FOCUSFLOW_KEYSTORE_BASE64`：`.jks` 文件的单行 Base64
- `FOCUSFLOW_SIGNING_STORE_PASSWORD`：keystore 密码
- `FOCUSFLOW_SIGNING_KEY_ALIAS`：key alias
- `FOCUSFLOW_SIGNING_KEY_PASSWORD`：key 密码

工作流会在临时 Runner 中解码签名文件；三个必需 Secret（keystore、keystore 密码、key 密码）任一缺失时构建会直接失败，绝不回退为 debug 签名；不配置 key alias 时自动使用 keystore 中的唯一私钥。
