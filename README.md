# FocusFlow

本地优先的 Android 日程与执行辅助应用（`com.sakata.focusflow`）。核心目标不是维护一张完整日历，而是**降低记录压力、按当前状态调整提醒、在错过计划后帮助恢复**。

当前版本：**6.0.0**（versionCode 460）。完整更新记录见 [CHANGELOG.md](CHANGELOG.md)。

> 数据原则：只用你确认过的数据生成建议，数据不足时不打扰、不假装精确。数据只保存在本机。

## 功能概览

**四个入口**
- 今日：状态与下一步、收集箱、今日餐点、睡前减速
- 日程：日／周时间轴，任务与活动可改期、完成、删除
- 计划：课表、空挡、目标与教程、每周回顾与 AI 周总结
- 设置：提醒打扰控制、外观（含深色）、习惯基线、前台应用检测、稳定性与崩溃记录

**课表与空挡**
- 课表截图识别（可选硅基流动视觉模型 Qwen3-VL）+ 手动录入，楼级自动归并、冲突提示
- 空挡 / 自由时段扣除课程与已有安排；「空挡适合做什么」给出内容建议并一键排入（结合精力规律、地点提示、历史完成率排序）

**目标与执行**
- 目标 = 预期结果 + 每周次数 + 单次时长 + 最低版本；按空挡自动排本周目标
- 完成率学习：自动排优先历史完成率高的时段
- 教程资料：收集、设为标准、AI 总结、视频分析一站式整理、学习路径建议

**活动与自律**
- 活动模式：开始前约定结束时间与下一步，到点转场、限次延长
- 安排空闲活动（游戏/视频/学习/休息/运动/自定义）：到点提醒开始与收尾，游戏/视频到点检测前台应用

**生活与习惯**
- 习惯基线：生活阶段（假期/上学/考试周）+ 多方案 + 按星期分组作息
- 饭点学习、睡前减速、精力记录（状态询问）
- 提醒打扰控制：免打扰时段 + 一次性静音

**外观与稳定性**
- 四套内置主题 + 自定义配色预设 + 深色模式
- 本地崩溃上报（设置 → 稳定性与崩溃）
- 单元测试：18 个测试类、72 条断言（`gradle test`）

## 构建

目标设备需 **Android 8.0（API 26）** 或更高。

```bash
# 用 Android Studio 打开本目录；或命令行构建
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

运行单元测试：

```bash
gradle :app:testDebugUnitTest
```

## 发布

GitHub Actions 会在每次 push 时自动跑单元测试并构建 debug APK（artifact）。正式发布请通过 **Releases** 上传手动签名的 APK。

## 模型（可选联网功能）

- 文本 / 视频分析 / 周总结：`Qwen/Qwen2.5-7B-Instruct`（免费默认）、`deepseek-ai/DeepSeek-V4-Flash`
- 课表视觉识别：`Qwen/Qwen3-VL-8B-Instruct`（免费默认）等
- key 仅存本机，只发往 `api.siliconflow.cn`
