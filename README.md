## 功能概览

**四个入口**
- 今日：今天的课程与已安排待办、需要处理、快速收集与明天预览；只呈现已有事实和用户选择
- 日程：日／周时间轴，任务与活动可直接开始、改期、完成或删除
- 计划：待办、计划与目标、课程、空挡建议、历史、资料和暂停项目；低频维护按需进入
- 设置：高频提醒、外观和作息留在首页；地点、AI、识别、应用检测与稳定性统一进入高级工具

**课表与空挡**
- 浙江大学教务课表导入：计划 → 课程 → 从教务网导入 → 浙江大学，在应用内输入账号密码后自动完成统一身份认证、学期读取与课表获取，并显示分阶段进度；密码经当前 CAS 公钥加密且只在本次内存会话中使用，不保存、不记录；新课进入待确认，唯一匹配的已有课程自动更新，歧义项不覆盖
- 空挡 / 自由时段扣除课程与已有安排；「空挡适合做什么」给出内容建议并一键排入（结合精力规律、地点提示、历史完成率排序）

**目标与执行**
- 目标 = 预期结果 + 第一步行动 + 完成标准 + 每周次数 + 单次时长 + 最低版本；按空挡自动排本周目标
- 完成率学习：自动排优先历史完成率高的时段
- 每个目标独立关联真实资料；常用标记不自动套用。AI 搜索只生成候选行动，确认真实资料后才保存

**活动与自律**
- 活动模式：开始前约定结束时间与下一步，到点转场、限次延长
- 安排空闲活动（游戏/视频/学习/休息/运动/自定义）：按真实类别提醒开始与收尾，通知送达不会自动写入“正在娱乐”；仅游戏/视频在已授权时检测前台应用

**生活与习惯**
- 习惯基线：生活阶段（假期/上学/考试周）+ 多方案 + 按星期分组作息
- 饭点学习、睡前减速、精力记录（状态询问）；饭点忽略后当天不重弹，次日自动续排
- 提醒打扰控制：免打扰时段 + 一次性静音

**外观与稳定性**
- 主入口之间左右平移（普通 80dp、跳转 96dp），底栏固定；子页从底栏对应图标放大展开、返回时缩回同一图标并同步淡出（深度缩放），底栏所属入口在子页时显示圆环并替换为子页短名。
- 根页面返回需二次确认（提示 4 秒内再次返回才退出），可点「不再提示」永久关闭，设置 → 退出确认 可改回；非今日页先回今日主页。回退／折返键为底栏两端圆瓣形变，有历史时伸出、无历史时收回，长按回退键弹会话历史列表；弹窗草稿关闭后重开自动恢复。
- 设置 → 检查更新：默认只接受本项目 GitHub 正式版（tag vX.Y.Z）；可勾选「接受候选版」，同基号比较 rc 序号，草稿始终忽略。下载成功后交系统安装器核验与安装，可开启自动检查。
- 维护者定稿的 B1“半透明流动丝带＋聚焦框＋流动 F”矢量应用图标，自适应桌面裁切，Android 13+ 支持单色主题图标。顶部安全留白随正文滚动，初始标题不被状态栏遮住；滚动时可延伸到状态栏后并柔和渐隐，不再被下沿固定裁断。
- 底栏叠放在页面上，内容可滚到栏后，只有列表末尾预留实测底栏高度；选中态为图标后**会平移的圆形色块**（从上一个页签滑到当前页签，约 260ms，随动画速度换算），进入子页时改为圆环。系统安全区、窄屏、大字体及键盘避让保留。
- 七套内置六色主题 + 自定义六色预设 + 深色模式；支持独立导航栏色、自动对比文字和五种卡片材质。兼容旧五色存档及已有颜色编码。
- 设置 → 外观 新增「动画速度」四档（关闭／较快／标准／较慢），统一作用于页面转场、底栏形变与选中色块；系统「移除动画」设置仍然生效。
- 弹窗改为页内浮层：打开弹窗时悬浮底栏（含回退／折返键）仍在最上层、可点，不再被系统窗口整层盖住；弹窗从屏幕下方上下平移进出；点入口、按上一步／下一步或跳转都会先关闭弹窗；返回键与点弹窗外面都能关闭，点弹窗卡片本身不会穿透关闭；键盘弹出时弹窗整体上移到键盘与底栏之上。全部 53 处弹窗统一外观（28dp 圆角、24dp 内边距、同 Material3 字体与按钮排布）。
- 应用锁定竖屏（横屏几何作为大屏/分屏兜底保留）；子页放大／缩小转场不再每帧重组整页，release 包实测重帧从 17.5% 降到 4.2%。
- 本地崩溃记录（设置 → 稳定性与崩溃：查看／复制／清空，不上传）
- 纯 Kotlin 单元测试覆盖数据兼容、时间轴、规划、提醒策略、外观存档、目标执行依据、导航历史与转场规则；实际数量以当前 CI 报告为准。

## 构建

目标设备需 **Android 8.0（API 26）** 或更高。

```bash
# 用 Android Studio 打开本目录；或命令行构建（仓库未附带 Gradle wrapper，需本机安装 Gradle 8.11.1）
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

运行单元测试（CI 同时验证 debug 和 release；分发 release APK）：

```bash
gradle :app:testDebugUnitTest :app:testReleaseUnitTest
```

## 发布

GitHub Actions 在 main 的 push、面向 main 的 pull request 或手动运行时执行单元测试并构建稳定签名 APK（artifact）；普通功能分支 push 不会单独触发。APK 和 artifact 名称包含 Actions run 编号。通过自动测试只能分发候选包，正式版需通过发布工作流建立非 prerelease GitHub Release。

7.1 起任务历史不再按 1000 条截断，界面仍只展示最近事件；已有 JSON 字段与存储键不变。旧版本已截掉的记录无法恢复。原始习惯事件独立保留最多 500 条，可浏览全部保留记录并逐条删除。损坏数据备份失败时暂停所有本地设置写入并显示提示，释放空间后可重试。

### CI 覆盖安装签名

为保证 Actions 产物能覆盖安装已有 FocusFlow，仓库使用下列四个 GitHub Actions Secrets（不要提交到仓库）：

- `FOCUSFLOW_KEYSTORE_BASE64`：`.jks` 文件的单行 Base64
- `FOCUSFLOW_SIGNING_STORE_PASSWORD`：keystore 密码
- `FOCUSFLOW_SIGNING_KEY_ALIAS`：key alias
- `FOCUSFLOW_SIGNING_KEY_PASSWORD`：key 密码

工作流会在临时 Runner 中解码签名文件；三个必需 Secret（keystore、keystore 密码、key 密码）任一缺失时构建会直接失败，绝不回退为 debug 签名；不配置 key alias 时自动使用 keystore 中的唯一私钥。
